## 一、这条路线解决什么问题

大部分人学矩阵卡在同一个地方：会算，但不知道为什么这么算。

- 矩阵乘法为什么要"行乘列"？不知道，背公式。
- 行列式为什么等于面积？不知道，只会展开。
- 秩是什么？"非零子式的最高阶数"——记不住，也不知道在说什么。

根因是**顺序反了**：教材先给定义再给意义，人先看到符号再找感觉。这条路线反过来：**先看到动作，再给符号**。

所以整条路线只有一个组织原则：每个模块都从一个能看见的画面进入，落到一个必须会的算法上。

## 三、九个模块（每个模块固定五栏）

### 0｜矩阵是什么：一摞数字其实是一个动作

| 项 | 内容 |
|---|---|
| 一句话本质 | 矩阵是把空间里的点搬到另一个点的规则；两列就是 i、j 两个基向量被搬到了哪 |
| 必须会 | 读出一个 2×2 矩阵把 (1,0)、(0,1) 搬到了哪 |
| 最容易错 | 把矩阵当成"数据的表格"而不是"变换"，后面全部跟着错 |
| 5 分钟自检 | 给 [[2,0],[0,3]]，问：正方形 (0,0)-(1,1) 被搬到哪？面积变几倍？ |
| 可玩点 | 拖动四个数字，右边方格纸上的网格实时跟着变形 |

### 1｜形状与运算：加法、数乘、转置

| 项 | 内容 |
|---|---|
| 一句话本质 | 加法和数乘是"同一个动作的叠加与放大"，转置是"换个角度看同一组数据" |
| 必须会 | 同形才能相加；数乘逐元素；转置行列互换、(AB)ᵀ=BᵀAᵀ |
| 最容易错 | (AB)ᵀ 写成 AᵀBᵀ；把 1×n 和 n×1 当同一个东西 |
| 5 分钟自检 | A 是 2×3、B 是 3×4，AB 是什么形状？BA 存在吗？ |
| 可玩点 | 两个变换并排，滑块调系数，看合成后的网格 |

### 2｜矩阵乘法：行乘列 = 两个动作接起来

| 项 | 内容 |
|---|---|
| 一句话本质 | AB 的意思是"先做 B，再做 A"；行乘列只是这个意思的计算写法 |
| 必须会 | 手算 2×2、3×3 乘法；判断能否相乘；知道 AB≠BA |
| 最容易错 | 顺序反了（AB 与 BA 是两个不同动作）；维度对不上还硬乘 |
| 5 分钟自检 | 先旋转 90° 再水平拉伸，和先拉伸再旋转，结果一样吗？ |
| 可玩点 | 积木式拼接：左边一列变换卡、右边一列，只有维度对得上才能扣在一起，扣上就播放合成动画 |

### 3｜行列式：这个动作把面积放大了几倍

| 项 | 内容 |
|---|---|
| 一句话本质 | det 是面积的缩放倍数；为 0 就是把平面压成一条线（信息丢了） |
| 必须会 | 2×2 直接算；3×3 用展开或化三角；det(AB)=det A·det B |
| 最容易错 | 负号的含义（翻转，不是"变小"）；把 det=0 只当成"算出来是 0" |
| 5 分钟自检 | det = -3 的变换，面积变几倍？朝向变了吗？ |
| 可玩点 | 拉动两个基向量，实时显示"面积 ×N"，压到共线时 det 跳到 0 并提示"平面被压扁" |

### 4｜逆与消元：这个动作能不能撤销

| 项 | 内容 |
|---|---|
| 一句话本质 | 逆矩阵就是"倒带"；可逆 ⇔ det≠0 ⇔ 没有把任何方向压没 |
| 必须会 | 2×2 伴随矩阵求逆；高斯消元；初等变换不改变可逆性 |
| 最容易错 | 求逆时忘记除以 det；消元过程中把"行变换"和"列变换"混用 |
| 5 分钟自检 | 给一个 det=0 的矩阵，要求求逆——错在哪一步？ |
| 可玩点 | 一键"倒带"：点一下，变形后的网格沿原轨迹退回，det=0 时按钮灰掉并解释为什么退不回去 |

### 5｜秩：这个动作还剩几个有效方向

| 项 | 内容 |
|---|---|
| 一句话本质 | 秩 = 变换后空间的维数；秩 1 是把平面压成一条线，秩 0 是压成一个点 |
| 必须会 | 行阶梯形求秩；秩 = 列空间的维数 = 独立列的个数 |
| 最容易错 | 把"矩阵大小"当"秩"；忘了秩 ≤ min(m,n) |
| 5 分钟自检 | 一个 3×3 矩阵秩为 2，它的零空间是几维？ |
| 可玩点 | 一堆箭头撒在平面上，拖动它们，实时高亮"哪几个是多余的"，右上角显示张成的维数 |

### 6｜方程组：解的结构就是几何的相交方式

| 项 | 内容 |
|---|---|
| 一句话本质 | Ax=b 是"哪个点被搬到了 b"；解的存在性看 b 在不在列空间里 |
| 必须会 | 增广矩阵消元；齐次解 + 特解 = 通解；基础解系维数 = n - r |
| 最容易错 | 把"无解"和"无穷多解"混为一谈；通解漏掉齐次部分 |
| 5 分钟自检 | 三条直线两两相交但不同过一点，对应秩是几？ |
| 可玩点 | 三条直线可拖，实时判定唯一解/无解/无穷多解，并回填对应的秩 |

### 7｜特征值：这个动作里方向不动的轴

| 项 | 内容 |
|---|---|
| 一句话本质 | 特征向量是被变换后方向不变、只被拉长的那些方向；特征值是拉长的倍数 |
| 必须会 | 特征多项式求特征值；求特征向量；判断能否对角化 |
| 最容易错 | 特征向量不唯一（差一个倍数）；把"有重根"直接等于"不能对角化" |
| 5 分钟自检 | 一个只做水平拉伸的变换，特征向量是哪两个方向？ |
| 可玩点 | 平面上撒满方向箭头，拖动变换，只有落在"不动方向"上的箭头保持笔直，其余全部偏转 |

### 8｜二次型：形状由矩阵决定

| 项 | 内容 |
|---|---|
| 一句话本质 | xᵀAx 是"用矩阵给每个方向打分"，等值线画出来是椭圆还是双曲线，由 A 决定 |
| 必须会 | 写出二次型矩阵；配方法/正交变换化标准形；正定判定（顺序主子式） |
| 最容易错 | 二次型矩阵要对称化（交叉项系数减半）；正定与"所有元素为正"无关 |
| 5 分钟自检 | x²+4xy+y² 对应的矩阵是什么？正定吗？ |
| 可玩点 | 拖系数看等值线在椭圆/双曲线/两条直线之间连续变形，正定性用颜色标出来 |

### 9｜SVD（选做）：任何动作 = 旋转 + 拉伸 + 旋转

| 项 | 内容 |
|---|---|
| 一句话本质 | 任意矩阵都能拆成"转-拉-转"，是特征值分解对非方阵的推广 |
| 必须会 | 知道 UΣVᵀ 三段各是什么；用奇异值解释降维/压缩 |
| 最容易错 | 把左奇异向量和右奇异向量搞反 |
| 5 分钟自检 | 一个把圆变成椭圆的变换，长轴短轴长度对应什么？ |
| 可玩点 | 三段动画依次播放：先转、再拉（长短轴可视化）、再转，回放可单步 |

## 六、"教程 + 小工具"怎么配

小红书这边的形态，我建议一个模块配一个可玩装置，教程只做装置的说明书：

```
一条笔记（图文/视频）
  ├─ 封面：一个反直觉的画面（比如"面积变成 0 的瞬间"）
  ├─ 正文：三句话说清这一集的动作
  └─ 挂载小工具：进去自己拖两下
```

理由很直接：矩阵这件事，看文字十遍不如自己把一个向量拖歪一次。教程负责"勾起来"，工具负责"讲明白"。

单集长度控制在：笔记 150–250 字、工具内 3–5 个操作、30 秒内出第一个"哦——"。

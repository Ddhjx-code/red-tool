# 「非遗手作坊」国风互动小工具系列规划

> 响应小红书科技薯「国风 vibecoding」共创计划：让文物、非遗、国风文化从「看」变成「玩」。
> 每个工具是一个独立离线 H5 zip 包（小红书小工具容器规范），共享一套视觉语言。

- 创建日期：2026-08-12
- 状态：规划中
- 构建规范依据：`.skill/SKILL.md`（minitool-zip-builder v1.2.0）及其 references

---

## 1. 系列定位

一句话：**把中国传统文化做成可以上手玩、上手做的互动体验，而不是图文介绍。**

三条选题原则：

1. **参与感** — 用户必须动手（剪、拼、画、猜、印），不是被动阅读
2. **可分享** — 有成品时刻（展开剪纸、拼合文物、套印完成），可经端能力 `postNote` 直接发笔记 / `saveImageToPhotosAlbum` 存相册，截图亦可
3. **文化准确** — 知识点（文物信息、非遗工序、灯谜出处）需有据可查

## 2. 技术约束摘要（详见 `.skill/references/`）

| 约束 | 影响 |
| --- | --- |
| 纯离线，不联网 | 所有资源打进 zip；数据用包内 JSON |
| `index.html` 必须在 zip 根目录 | 打包时压缩目录内容而非目录本身 |
| 禁内联脚本 / 行内事件 | JS 外置 + `addEventListener` |
| 禁剪贴板 / 下载 / 外链跳转 | 成品出口走端能力 JS API（见下），不再靠用户截图 |
| 禁传感器（含重力感应） | 不做摇一摇 / 倾斜类交互 |
| 可用：Canvas 2D / WebGL / 触摸 / localStorage / 选图 / 相机 | 核心玩法基础 |

| 包体 ≤10MB，建议 <2MB | 图片必须压缩，优先程序化生成视觉 |

## 4. 单工具设计简报

### 4.1 打铁花·火树银花（首发，工序体验型模板验证）

五幕流程，每幕一个场景，点按推进：

| 幕 | 工序 | 互动 | 知识点 |
| --- | --- | --- | --- |
| 1 | 备铁 | 点选废铁/铁砂投入坩埚 | 为何用废铁（含碳高、易熔） |
| 2 | 熔铁 | 长按风箱鼓风，炉温条升至 1600°C | 温度够高铁水才能「散」成花 |
| 3 | 舀铁水 | 拖动柳木勺舀起铁水 | 柳木勺浸水碳化故不烧 |
| 4 | 打铁花 | 点按抛起铁水 → 再点挥板击打 → 粒子炸裂成漫天铁花，连击越多花越盛 | 核心玩法：时机/节奏 |
| 5 | 成焰 | 「火树银花不夜天」全景 + 知识卡 | 截图分享时刻 |

- **技术方案**：Canvas 2D 粒子系统（重力+阻力+色温衰减）表现铁花；炉火/铁水/夜空/城墙剪影全部程序化绘制；步骤状态机驱动场景切换
- **知识卡内容**：河北暖泉镇/山西泽州，国家级非物质文化遗产，源于北宋，千年历史
- **素材**：零外部素材；音效可选（体积权衡，默认无）
- **验收**：五幕闭环流畅、打铁花粒子效果有冲击力、知识准确、包体 <1MB
- **模板沉淀**：抽象「工序体验」骨架（步骤状态机 + 场景组件 + 知识卡 + 高光时刻），供后续皮影戏/糖画/景泰蓝等复用

### 4.2 剪纸工坊

- **玩法**：选折法（三折/四折/五折/八角）→ 在折好的扇形区域内触摸剪出洞与边纹 → 「展开」动画呈现完整剪纸 → 换底色（红纸/窗花场景）截图分享
- **技术方案**：Canvas 2D。剪裁用 `destination-out` 笔刷在扇形 wedge 上擦除；展开时按折数镜像旋转复制 wedge；展开动画用逐帧扇形展开
- **关键体验点**：剪刀手感（笔刷大小/边缘柔化）、展开瞬间
- **素材**：零外部素材；可选内置 2-3 个示范剪法引导
- **验收**：折/剪/展开闭环流畅，成品适合截图，包体 <500KB

### 4.3 文物修复局

- **玩法**：选文物（青铜器/瓷器/陶俑）→ 碎片散落在「修复台」→ 拖拽旋转拼合 → 完成后「修复报告」（文物名称/年代/馆藏/知识点）→ 下一件
- **技术方案**：Canvas 拼图（碎片为不规则路径切片），吸附判定 + 完成动效；知识数据放包内 JSON
- **关键风险**：文物图片版权 → 只用公有领域文物图（博物馆开放资源）或自绘插画；webp 压缩控制体积
- **验收**：3 件以上文物关卡，单件碎片 8-16 片，整包 <2MB

### 4.4 猜灯谜

- **玩法**：灯笼夜市视觉，逐盏灯笼点题，答对点亮；题目分类（字谜/物谜/诗谜）；本地记录战绩
- **技术方案**：DOM + CSS 动画为主，题库 JSON（≥60 题，附出处）
- **验收**：答题闭环、错题揭晓答案、localStorage 进度

### 4.5 水墨小品

- **玩法**：毛笔笔刷（提按出粗细、飞白、墨色浓淡）画山水/花鸟 → 题字 + 红印 → 装裱成轴/扇面分享
- **技术方案**：笔刷 = 沿笔迹多戳点叠加 + 噪声透明度模拟洇墨；装裱边框程序化绘制
- **关键风险**：笔刷手感需要反复调优
- **验收**：笔触有水墨质感，装裱成品适合截图

### 4.6 木版年画套印

- **玩法**：选线版（门神/连年有余）→ 按真实工序逐版套色（每版一色，对位盖章式上色）→ 完成成品 + 工序科普
- **技术方案**：线稿 + 分色版图层（PNG/SVG），点击/拖动「刷色」逐版显色
- **关键风险**：线稿与分色版素材需要绘制（可先做 1 张验证）
- **验收**：≥1 张完整年画，套印工序讲解准确

### 4.7 篆刻工作室

- **玩法**：输入 2-4 字 → 选印式（朱文/白文）与边框风格 → 生成印面 → 钤印到宣纸效果分享
- **技术方案**：篆体字渲染（woff2 子集化字库 或 内置常用字 SVG 字形）+ 印面做旧噪声
- **关键风险**：**篆体字库版权**——未确认免费可商用字库前不启动；其次子集化体积控制
- **启动前置**：确认字库授权方案

## 5. 共享视觉规范（系列统一）

- **配色基调**：中国传统色 —— 朱红 `#C3272B`、黛青 `#425066`、藤黄 `#FFB61E`、月白 `#D6ECF0`、宣纸底 `#F5F0E6`
- **字体**：系统字体栈（容器建议），标题可用楷体/宋体风格 fallback：`"Kaiti SC", "STKaiti", "KaiTi", serif`
- **结构统一**：首页（系列标识 + 工具入口意象）→ 操作区 → 成品/分享时刻 → 「再玩一次」；顶部留安全区 `var(--safe-area-inset-top, env(safe-area-inset-top, 0px))`
- **成品时刻**：每个工具必须有明确的「完成画面」，为截图分享优化（3:4 竖屏友好）

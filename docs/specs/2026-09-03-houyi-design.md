# 后羿射日 · 设计文档

> 非遗手作坊系列第 18 作。经典换皮·物理益智（愤怒小鸟模式）：拉弓射金乌，扶桑树结构坍塌。
> 创建日期：2026-09-03

## 1. 选题依据

- **形式**：经典换皮·物理益智（愤怒小鸟模式）——系列新形式（之前做过跑酷/合成/换装/战棋/STG）。
- **机制映射完美**：弓=弹弓（拉弓蓄力天然映射）、箭=抛射物、金乌=目标、扶桑树=可破坏结构、射九日留一日=win 机制。
- **文化厚重**：后羿射日神话（《淮南子》《山海经》《楚辞·天问》），视觉震撼（金乌/扶桑树/后羿）。
- **系列契合**：山海御空已是山海经 STG，神话主题已建立。

## 2. 文化准确性（调研结论）

- **后羿射日**：《淮南子·本经训》「尧之时，十日并出，焦禾稼，杀草木，而民无所食…尧乃使羿…上射十日而下杀猰貐」。
- **金乌/三足乌**：日中之鸟（《淮南子·精神训》「日中有踆乌」，郭璞注「中有三足乌」）。十日是帝俊与羲和之子，金乌化身，三足踆乌，会飞的太阳神鸟。
- **扶桑树**：《山海经·海外东经》「汤谷上有扶桑，十日所浴，在黑齿北。居水中，有大木，九日居下枝，一日居上枝」。扶桑=世界树，金乌栖息地。三星堆青铜神树≈扶桑树（文物佐证）。
- **后羿弓矢**：《山海经·海内经》「帝俊赐羿彤弓素缯，以扶下国」——彤弓（红弓）素缯（白箭）。
- **射九日留一日**：王逸注《楚辞》「羿仰射十日，中其九日，日中九乌皆死，堕其羽翼」——射落九日，留一日。

## 3. 核心机制（愤怒小鸟模式）

| 愤怒小鸟 | 后羿射日 |
| --- | --- |
| 弹弓（拉弓蓄力） | 彤弓（拉弓蓄力） |
| 小鸟（抛射物） | 素缯白箭 |
| 猪（目标） | 金乌（三足乌） |
| 猪堡垒（可破坏结构） | 扶桑树（枝干）+ 日轮（太阳轮） |
| 抛物线轨迹预览 | 箭的抛物线轨迹（金色虚线弧） |
| 消灭全部目标 | 射落全部金乌（射九日留一日） |

**玩法循环**：拉弓瞄准（轨迹预览）→ 放箭 → 箭撞扶桑树/日轮结构坍塌 → 砸落/射中金乌 → 限箭数内射落全部金乌过关。

## 4. 物理碰撞方案（重中之重）

> 用户明确要求：文生图素材 + 每个素材按轮廓定制碰撞体（非矩形）+ 碰撞准确性是命门。这类游戏碰撞就是玩法本身，矩形包围盒会产生「幽灵碰撞区」（箭射中素材周围空白角也算碰撞），手感崩。

### 4.1 轮廓定制碰撞体（非矩形）

每个素材的物理碰撞体必须贴合其视觉轮廓：

| 素材 | 视觉 | 物理碰撞体（Matter.js） |
| --- | --- | --- |
| **金乌**（三足乌） | 鸟形 | `Bodies.fromVertices`（鸟身轮廓多边形）或 `Bodies.circle`（身体圆），**非矩形** |
| **日轮**（太阳轮） | 圆环 | `Bodies.circle`（圆），**非矩形** |
| **扶桑树**（枝干） | 弯曲枝干 | `Bodies.fromVertices`（枝干轮廓多边形），**非矩形** |
| **箭**（素缯） | 细长箭 | 细长多边形/capsule，**非宽矩形** |

**实现要点**：
- `Bodies.fromVertices(x,y,vertexSets)` 支持任意轮廓顶点；凹多边形（鸟形/枝干）用 **decomp 分解**成凸块（Matter.js 内置 decomp 或 poly-decomp 库）。
- **轮廓来源**两条路：
  - ① **手工定义**每类素材的轮廓顶点（可靠可控，推荐主路）
  - ② **alpha 通道提取**：从文生图素材的 alpha 通道用 marching squares 描边 → 简化（Douglas-Peucker）→ decomp 分解（更贴合但复杂，可选）
- **碰撞体 = 视觉轮廓**：箭射中金乌鸟身才算命中，射中空白角不算——碰撞准确，手感对。

### 4.2 异形堆叠稳定性（关键难点）

不规则形状（弯曲枝干/圆环）堆叠稳定性不如矩形（愤怒小鸟的塔是矩形块好堆叠）。解决方案：

- **设计平整接触面**：扶桑树枝干分段带**平端**（可堆叠），日轮设计成可**平衡堆叠**的圆（或带平底）。
- **混合结构**：扶桑树主干（竖直多边形）+ 日轮（圆，可堆叠/平衡）+ 金乌（栖于顶端）。堆叠围绕这些形状设计。
- **Matter.js 稳定堆叠**：`Engine.create({ enableSleeping: true })` 让近静止 body 休眠 → 结构稳定不抖动。
- **坍塌涌现**：移除/损坏底层块 → 重力 + 求解器自然倾倒其余（无需脚本），这是愤怒小鸟破坏的核心技巧。

### 4.3 碰撞伤害（每材质 HP）

- `collisionStart` 事件 + **相对速度**算冲击（比 penetration.depth 更物理，匹配「快箭=大伤害」）。
- 每材质 HP：扶桑树（木）低 HP、日轮（石/金属）高 HP、金乌（鸟）直接击杀。镜像愤怒小鸟 wood/ice/steel 分级。
- HP ≤ 0 → 移除 body + 碎屑粒子。

## 5. 技术实现

### 5.1 物理引擎：Matter.js（确认最优）

- **83KB min / 26KB gzip**，仅占 2MB 预算 ~4%——物理非瓶颈，美术素材才是预算大头。
- **已在系列**（科举合成内嵌 Matter.js 0.19.0），复用零新增依赖风险。
- **用法**：headless 引擎（不用 `Matter.Render`）+ 自写 Canvas 2D 渲染（读 `body.position`/`body.angle` 画），固定步长 `Engine.update(engine, 1000/60)` 在自己的 rAF 循环。

### 5.2 弹弓发射：Pattern B（拖动矢量→setVelocity）

- **关键决策**：用 Pattern B（拖动矢量→`Body.setVelocity`）而非 Pattern A（弹簧 constraint-release）。
- **原因**：Pattern A 的发射速度从物理求解器涌现（无显式 vx,vy 矢量），**无法做轨迹预览**（所有教程都没轨迹预览正因用了 A）。Pattern B 给出显式 (vx,vy)，解锁轨迹预览，且「限箭数」可计数、更确定。
- **实现**：pointerup 时算拖动矢量 → `power = min(hypot(dx,dy), MAX_PULL) * POWER_SCALE` → `Body.setVelocity(arrow, {vx,vy})`。弓弦装饰性绘制。

### 5.3 轨迹预览（金色虚线弧）

- **解析抛物线**（用引擎自身 gravity，否则预览骗人）：
  ```js
  function drawTrajectory(ctx, launchPos, vx, vy, gravity, steps=40) {
    let x=launchPos.x, y=launchPos.y, cvx=vx, cvy=vy;
    for (let i=0; i<steps; i++) {
      cvy += gravity; x += cvx; y += cvy;
      if (i%3===0) { /* 画金色点，半径随 i 衰减（虚线渐隐）*/ }
    }
  }
  ```
- 仅拖动时绘制（pointerdown→pointermove），放箭时清除。

### 5.4 结构构建 + 坍塌

- **构建**：`Composites.stack`/`Composites.pyramid` 堆叠扶桑树/日轮（带每材质 `plugin.hp`）。
- **破坏**：`collisionStart` → 相对速度冲击 → 扣 HP → HP≤0 移除 body + 碎屑粒子。坍塌涌现（重力倾倒其余）。
- **win**：全部金乌 body 消灭 → 过关。

### 5.5 关键 gotchas（必须纳入）

- **箭速封顶**（防穿透薄块，Matter.js 无 CCD）：`Body.setSpeed(arrow, MAX_SPEED)`。
- **固定步长**（轨迹预览确定性）：`Engine.update(engine, 1000/60)` 固定 delta，非变量 dt。
- **enableSleeping**（结构稳定+性能）。
- **devicePixelRatio 缩放**（移动端触摸）。

## 6. 关卡设计

- **叙事框架**：射九日留一日（神话）。游戏跨关卡射落 9 金乌，留最后一日（结局叙事）。
- **关卡**：每关一个扶桑树结构 + 金乌栖息。玩家射箭消灭金乌（直射或坍塌结构砸落）。
- **限箭数**：每关有限箭数（如 3-5 箭），箭尽未灭全部金乌则失败。
- **难度递进**：
  - 第 1 关：1 金乌 + 简单扶桑树（教学）
  - 第 2-3 关：多金乌 + 复杂结构（日轮堆叠）
  - … 递进至 9 金乌（射九日）
  - 最终：留一日（结局叙事，不射最后一日）
- **关卡数**：建议 5-7 关（每关 1-3 金乌，递进结构复杂度）。

- 日期：2026-08-31

- 调研结论：GitHub 扫描确认 STG 是极成熟品类，开源实现多为 1945/雷电复刻，无玩法创新空间——**乐趣在经典循环本身**，改编重点在题材包装 + 移动端手感

## 0. 调研结论（STG 玩法设计）

**品类共识（雷电/1945/Raiden Fighters 提炼）**：
1. 玩家在屏幕下方，**全向移动**（不只是左右），躲避弹幕
2. **自动射击**或按住连发——移动端必须自动射击（手指用于移动）
3. **火力升级**是核心爽点：吃道具升武器（单发→双发→散射）
4. **炸弹**（清屏大招）是保命底牌，限量，制造紧张感
5. **波次 + 关底 Boss**：杂兵波次推进，关底 Boss 血条压制
6. 弹幕分两类：可预判的规律弹（躲）+ 随机弹（反应）

**移动端适配（区别于街机）**：
- 手指拖拽移动（手指在飞机下方偏移，不挡视线）
- 自动射击，无需按住
- 单关 2-3 分钟（小红书场景）
- 判定框比视觉小（宽容判定，移动端手感）

**山海经题材映射**：
- 玩家 = 应龙（有翼神龙，御空）
- 敌机 = 妖兽（穷奇/毕方/蛊雕），从云海上方扑落
- 子弹 = 飞剑（散射）；炸弹 = 雷符；护盾 = 八卦镜
- Boss = 饕餮（贪食凶兽，血厚）
- 背景 = 云海卷轴（昆仑/不周山）

## 1. 核心循环

```
拖动应龙移动（自动射飞剑）→ 打落妖兽 → 吃掉落法宝升级
→ 躲妖兽弹幕 → 清完波次 → Boss 战 → 通关结算
```

## 6. 技术

- Canvas 2D 纵版卷轴，云海背景滚动
- 引擎：波次生成器 + 碰撞检测（玩家判定框 < 视觉）+ 掉落系统
- 素材：应龙 + 4 妖兽 + 3 法宝 + 云海背景，wan 生成 + rembg
- 无头钩子：?test=1 + window.__game（start/step/movePlayer/useBomb/snapshot）
- 冒烟：自动走位脚本验证三关可通关

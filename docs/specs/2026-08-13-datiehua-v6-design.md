## 0. 产品简报（本轮对话已确认）

| 项目 | 结论 |
| --- | --- |
| 面向谁 | 小红书国风兴趣用户，对打铁花零认知，3 秒注意力，单手拇指操作 |
| 提供什么 | **一次"亲手打一场打铁花"的体验**——会搞砸、能练好、每个人打出的结果不一样 |
| 用来干什么 | 体验震撼 + 打出属于自己的终章（截图时刻）+ 一行知识佐料 |
| 和视频的区别 | **有失败、有时机、有分支、有积累**——视频只有一个固定结果 |
| 图文 vs 工具 | 工具的价值 = 互动本身；「去哪看」等知识只做佐料，不做产出物 |
| 素材策略 | **零外部素材，全程序化**（图片质量不可控就不大范围用；v5 的 5 张插画不进 v6） |

## 1. 动效人格（从题材推导）

打铁花 = 仪式（低起、庄重）→ 爆发（峰值）。运动声音三个词：**沉、炸、息**。

| 态 | 用途 | 时值/缓动 |
| --- | --- | --- |
| 沉（蓄力） | 点炉、舀铁水、趁热等待 | 弧线 ≥3s，ease-in（前慢后快，用力感） |
| 炸（冲击） | 击打瞬间 | **冲击镜头**：0.1s ease-in-cubic crash-zoom 至 2.2×（打偏 1.7×）→ 冻结 3 帧 → 1.5s ease-out 慢放回全景；同步 7px 指数衰减抖动（τ=0.09s）+ 冲击闪。配方来源：video-shotcraft impact-feedback 卡 |
| 息（落定） | 每次绽放后、终章 | 落定 hold ≥1s，终章 hold ≥1.5s |

- 文字入场定式（全片统一）：**压印三件套** scale 1.6→1 + blur 6px→0 + opacity，逐字错峰；落定 hold ≥1s（硬底线）
- 确定性：全部 mulberry32 种子随机，禁 Math.random()

## 2. 能量弧（五幕，总时长约 40s + 重试）

| 幕 | 能量 | 占比 | 职责 |
| --- | --- | --- | --- |
| 一 · 熔铁 | 低 | ~10% | 仪式蓄力，建立「你是打花人」，教长按 |
| 二 · 舀铁水 | 中低 | ~7% | 呼吸拍 + **风险决策**（舀多舀少） |
| 三 · 打铁花 | 中→高（随连击爬升） | ~60% | 核心玩法：三回合、三种打法、可失败 |
| 四 · 成焰 | **峰值** | ~15% | 积累总爆发，riser→impact→sparkle 三拍 |
| 尾 | 低 | ~8% | 知识一行 + 落款 + 截图时刻 + 再打一场 |

失败预算：所有失败低成本重试（≤2s 回到出手点），不设「游戏结束」。

## 3. 配方卡（含失败分支与分支结果）

### 幕一 · 熔铁（长按鼓风）

- **交互**：长按任意处 → 风箱鼓风，炉温上升（非线性：`heat += dt*(0.22+0.28*heat)`，约 3s 满）
- **反馈全靠光**（无 UI 进度条，v4 纪律）：炉火亮度 ∝ 热度；余烬粒子上升速率 ∝ 热度；风箱声 ∝ 热度
- **分支**：松手 → 热度按 `0.08/s` 回落（轻压力，不是惩罚）；烧满 → 炉火一亮（easeOutExpo 0.4s）→ 呼吸 0.6s → 进幕二
- **声音**：风箱 = bandpass 噪声随长按起伏；炉火噼啪底噪随热度加密——这段本身就是 riser
- **文字**：竖排「打铁花」压印三件套入场，hold 1s；提示「长按 · 鼓风」
- **已知坑**：无进度条时，长按 0.5s 内必须给出可感知反馈（火苗一跳），否则用户不知道按住了

### 幕二 · 舀铁水（风险决策）

- **交互**：按住勺位 → 舀取，**按的时长决定舀量**（0.5~2.5s，三档：少/中/满）
- **分支（真实的风险回报）**：舀量不影响火候曲线，影响**花的规模与判定窗**——满勺更重，须更贴峰值出手：
  - 少勺（0.5~1s）：打准窗 火候≥0.75（约 0.64s），花规模 0.7×——稳
  - 中勺（1~1.8s）：打准窗 火候≥0.85（约 0.38s），花规模 1.0×——基准
  - 满勺（1.8~2.5s）：打准窗 火候≥0.92（约 0.2s），花规模 1.3×——险而盛
- **呈现**：勺中铁水光团随舀量变大变亮；无文字说明，用「光团越大、出手越沉」让玩家自己权衡
- **声音**：舀起 = 粘稠短音 + 炉火随舀量一闪
- **已知坑**：决策必须可读——光团大小差异要夸张到一眼可辨（至少 3 档亮度差）

### 幕三 · 打铁花（三回合 = 三流派，核心玩法）

每回合结构：**舀起（铁水在勺/棒上）→ 趁热出手（沉→炸）→ 花开（息）**。

**物理真实性（用户评审修正，2026-08-13）**：铁水是液体，不会聚成球飞上天等人打。真实打法是**击打/泼洒动作本身把铁水打出去**（确山下棒击上棒射向柳枝、暖泉舀泼城墙、泽州操板击打冲天）。因此没有「抛球→打顶点」，改为**趁热判定**：

- 舀起后铁水在勺上，火候曲线 `readinessAt(t)`：0.35s 聚拢达峰，随后 2.2s 冷却流失；勺上光团亮度 = 火候（光即反馈，无 UI 条）
- 出手判定（按出手时火候）：
  - **打准**（火候 ≥0.85，峰区约 0.38s 窗）：满树金花，该流派完整形态
  - **打偏**（≥0.4）：稀落几朵，规模 0.4×
  - **失手**（<0.4，太早没聚拢/太晚半冷）或**凉透**（火候归零未出手）：这勺作废，铁水坠地闷响、画面微暗 0.3s，**重新舀一勺**（≤2s）。计入终章成色
- 火候曲线随时长不变（三档舀量共用），舀量只影响花的规模与勺量风险回报

三回合（手势、花形、失败呈现各不相同——一种手法只当一次主角）：

| 回合 | 流派 | 手势 | 花形（分支结果） | 场景元素（程序化剪影） |
| --- | --- | --- | --- | --- |
| 1 | 确山 · 打花棚 | **点按**挥棒 | 铁汁击棚上柳枝迸散 + **鞭炮连锁**点燃 | 高花棚 + 柳枝 |
| 2 | 暖泉 · 打树花 | **横滑**泼洒 | 城墙上绽开**树冠形**分枝花 | 古城墙 |
| 3 | 泽州 · 打向天空 | **上挑**挥板 | 铁花**冲天**十几米，金粉拖尾 | 旷野 + 炉火 |

- 每回合开打前：一行流派小字压印入场（如「确山 · 打花棚｜挥棒击棚」），hold 0.8s——知识在玩的间隙进入，不讲课
- 连击反馈：连续打准 → 下一勺铁水更亮（光效递进，不做 UI 计数）
- **声音**：挥棒/泼洒/挥板 = 三种音色的 whoosh；打准 = 重 impact + 金属余韵；打偏 = 轻 impact；落空 = 低频闷坠；花开 = sparkle，连发**音量阶梯递减**（0.4→0.25）防机枪感
- **已知坑**：趁热窗按真机手感校准（首版峰区 0.38s 偏宽，视反馈收紧）；失手的挫败感靠「重新舀一勺」的快节奏化解，不做任何文字批评

### 幕四 · 成焰（终章 = 全片峰值）

- **触发**：三回合结束，自动进入
- **成色分支**（每个人的终章不一样）：终章规模 = f(三回合判定 + 舀量)
  - 全打准 + 满勺：「火树银花不夜天」满配——三种花形同场总爆发 + 金粉雨全屏
  - 有落空：规模按成色缩减，但完整收尾——**不惩罚，只区分**，激发「再打一场」
- **声音三拍句式**（定式，不许改）：riser 1.2s（能量铺垫）→ impact（全片最响）→ sparkle 余韵 2s
- **配方**：爆发 easeOutExpo → 飘落 1.5s → **hold ≥1.5s**（峰值必呼吸）
- **已知坑**：初版终章几乎必然偏保守——粒子规模默认按「前四版最大值的 1.5 倍」起调

### 尾声（截图时刻）

- 终章余韵未散时浮现：
  - 竖排一句：「匠人把危险留给自己，把美丽献给人间」压印入场，hold 1.5s
  - 底部两行小字（纹理态，弱化处理）：三流派 + 「始于北宋 · 国家级非物质文化遗产」
  - 落款「非遗手作坊 · 打铁花」+ 「再打一场」
- 此帧为截图优化（3:4 友好）：铁花余韵 + 竖排句 + 落款
- **声音**：余韵 sparkle 自然衰减，炉火底噪回到开场音量（首尾呼应）

## 4. 视觉方案

- **DOM/CSS 为骨**：标题/提示/流派小字/尾声/按钮全部 DOM，楷体 + 宣纸白 + 焦墨底，锐利可控
- **Canvas 只做火与光**：fixed 覆盖层，粒子/炉火/剪影（花棚/城墙/旷野程序化绘制）
- **Tokens**：墨 `#14161a` / 熔金 `#d4a24e`（唯一强调色）/ 金亮 `#f0c674` / 宣纸白 `#f2ede4`
- **粒子重写**（canvas-ui 技法移植，Canvas 2D）：
  - 预渲染光晕 sprite（禁逐帧径向渐变）；`lighter` 叠加
  - 生命包络 `smoothstep(0.02,0.2,life) × smoothstep(1,0.55,life) × 闪烁`
  - 色温 LUT：白热 `#fff7e0` → 金 `#ffd24a` → 橙 `#ff660d` → 烬 `#8b1a05`
  - 拖尾画布 `destination-out` 淡出（禁暗色 fillRect 淡出，会发灰）
  - 暖泉树冠 = 击墙分枝（代数衰减，gen ≤3）；落点光斑点亮墙面（点光源近似）
  - 粒子上限：移动 800 / 桌面 1500，对象池复用

## 5. 声音方案（WebAudio 程序化，零素材）

- 全部合成，真实物件质感（火/风/金属/闷响），**禁合成 UI 通知音**
- 事件驱动钉音（等价声明式钉帧表）：`SFX = { event, make, volume }[]` 集中管理
- 音量分层：impact 0.5（最响）/ whoosh 0.3 / sparkle 0.2~0.35 阶梯 / 底噪 0.08
- 主链路 DynamicsCompressor 防爆；右上角静音开关；iOS 首次手势解锁 AudioContext
- 声音在画面锁定后调（S3 纪律）——先默片跑通，最后配音

## 6. 工程结构

```
tools/datiehua/
├── index.html          # DOM 骨架：标题/提示/流派字/尾声/重玩/静音
└── assets/
    ├── style.css       # tokens + 排版（压印三件套动画）
    ├── main.js         # 五幕状态机 + 手势路由（长按/点按/横滑/上挑）
    ├── audio.js        # 新增：WebAudio 程序化声音
    ├── particles.js    # 重写：sprite 光晕 + 色温 LUT + 拖尾 + 分枝
    └── scenes.js       # 五幕配方卡实现（含判定/失败分支/成色计算）
```

- 保留复用：mulberry32、墨晕转场（回合间）、手势识别框架、无头验证管线
- 删除：v5 展签 DOM、img/ 插画引用（素材移出包体）
- 包体目标：<500KB（零素材后大幅缩减）

## 7. 验证（按 pipeline 顺序）

1. **Styleframe 先行**：纯 HTML/CSS 静态关键帧 3 张（开场标题 / 回合击打瞬间 / 尾声截图时刻），无头截图 → 用户目检版式，通过才写动效
2. 动效实现：每幕预声明 2 个验收帧（冲击瞬间 + 落定 hold），无头截图断言
3. 像素断言：终章帧金粉密度 > 阈值；尾声竖排句有效字高 ≥ 帧高 5%；全片无金粉外彩色
4. 声音：用户真机试听（无头听不了）
5. 打包前过 `.skill` 容器自检清单

## 8. 验收标准

- [ ] 失败分支存在且低成本重试（落空 → 重舀 ≤2s）
- [ ] 三回合手势/花形/失败呈现互不相同
- [ ] 舀量决策真实影响结果（窗口与规模差异可感知）
- [ ] 终章规模随成色变化（不同人打出不同终章）
- [ ] 文字两态清晰（要读 ≥5% 帧高；流派小字为纹理态）
- [ ] 声音三拍句式完整，可静音，无游戏提示音质感
- [ ] 零外部素材，包体 <500KB，粒子确定性可复现
- [ ] Styleframe 用户目检通过后才进入动效实现

## 9. 与 v5 的关系

- v5 互动展册废弃：展签式知识呈现、插画背景、五屏展览结构全部不要
- v5 可复用资产：粒子系统骨架、墨晕转场、手势识别、无头验证脚本
- 教训记录：①「留空」歧义提示词导致亮顶废图 ②cover 放大毁素材 ③展册无成品时刻、无失败、无分支——工具做成图文的代价

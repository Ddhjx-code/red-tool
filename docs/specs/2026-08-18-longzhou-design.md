# 龙舟破浪 设计文档

- 日期：2026-08-18
- 系列：「非遗手作坊」新增 #8（series-plan 待补录）
- 形式：经典玩法换皮——无尽换线跑酷 × 端午龙舟
- 素材：零外部素材，全程序化（Canvas 2D 绘制）

---

## 0. 产品定义

| 项目 | 结论 |
| --- | --- |
| 面向谁 | 小红书休闲玩家，30 秒上手，碎片时间反复开局 |
| 提供什么 | 一局 1-3 分钟的端午龙舟竞速：换线躲避、击鼓冲刺、收集风物解锁图鉴 |
| 用来干什么 | 爽感（速度+冲刺）+ 收集欲（端午图鉴 8/8）+ 战绩卡分享 |
| 视觉策略 | 全程序化伪 3D（背后视角），系列传统色；吸取打铁花教训——视觉方案先验证再堆内容，第一里程碑必须出「能看的」河面 |

用户已确认的四个方向决策：无尽攒分模式、背后伪 3D 视角、击鼓冲刺签名机制、图鉴收集式知识点。

## 1. 核心循环

```
首页 → 竞速（无尽）→ 翻船 → 结算（战绩+知识卡+称号）→ 再战/图鉴
```

### 1.1 竞速内

- 三航道江面，障碍从地平线涌来，基础速度随里程递增（8 → 22 m/s 线性，约 3 分钟到顶）
- **换线**：左右滑动切航道（也支持键盘 ←/→，便于无头测试与 PC 模拟器）
- **收集**：粽子=分数主力；雄黄酒=+50 鼓点槽；稀有风物=图鉴解锁+高分
- **击鼓冲刺**（签名机制）：连点鼓面攒鼓点槽（每点 +12，两次点击最小间隔 120ms），满 100 自动触发冲刺——3 秒内速度 ×1.8、无敌、撞碎障碍每只 +50 分，金色拖尾+鼓点滚奏；冲刺结束槽清零
- **受击**：撞障碍 = 扣 1 点「稳」（共 3 点，左上小鼓图标显示）+ 1.5 秒无敌闪烁 + 速度回落基础值 + 连击清零；「稳」归零 → 翻船动画（船倾+水花）→ 结算
- **连击**：无伤连续收集叠连击，倍率阶梯 ×1/×2/×3/×4/×5（连击 0/5/10/15/20 触发），受击重置
- **分数** = 粽子 10×倍率 + 冲刺撞碎障碍 50/只 + 里程累计（1 分/m）

### 1.2 难度曲线

| 里程 | 变化 |
| --- | --- |
| 0-200m | 只有礁石，密度低，教学期（首局浮层提示：滑动换线/点鼓冲刺） |
| 200m+ | 漩涡出现（视觉旋转，判定同礁石但更宽） |
| 500m+ | 浮木出现（横向缓慢漂移 1 条航道） |
| 800m+ | 障碍密度上限，纯拼速度反应 |

生成规则硬约束：任一 z 断面上三航道最多封 2 条，永远留活路（生成器校验）。

### 1.3 结算屏（成品时刻）

- 战绩：里程 / 总分 / 粽子数 / 最高连击 / 历史最佳
- 称号印章（朱红印章样式，按总分）：<500 见习桨手 / <1500 江上水手 / <3000 鼓手传人 / <5000 弄潮儿 / ≥5000 汨罗飞桨
- 随机端午知识卡 1 张（从已解锁图鉴抽）
- 图鉴进度 x/8
- 出口：再战一局 / 图鉴 / 存到相册 / 发笔记（Canvas 导出 → writeTempFile → saveImageToPhotosAlbum / postNote；`window.xhs?.miniTool` 判空降级为截图提示）
- 结算卡按 3:4 竖屏构图

## 4. 技术实现

- **渲染**：单 Canvas 2D，rAF 循环，dt 驱动；DPR 上限 2
- **伪 3D 投影**：相机在船后上方。物体距离 z（船体平面 z=0，远处 z→zMax），投影因子 `p = f / (f + z)`（f≈300 调参）；`y = horizonY + (baseY - horizonY) * p`，`x = cx + laneOffset[lane] * p`，尺寸 ×p。地平线约在画布高 32%
- **生成器**：按时间/距离节拍在 zMax 处生成障碍与收集物，队列驱动；同 z 断面 ≤2 条航道被封（硬校验）；收集物倾向放在可通行航道上（奖励走位）
- **状态机**：`home → playing ⇄ paused → capsized → result →(home|replay|codex)`；visibilitychange 自动暂停
- **输入**：触摸滑动（横向位移 >30px 且横向主导 → 换线，换线为 150ms 缓动位移）；鼓面按钮点按；键盘 ←/→/Space 等价映射
- **存档**：localStorage `{ best, bestDist, codex: [已解锁 id], runs }`
- **音效**：WebAudio 程序化——鼓点（低频膜鸣）、冲刺（滚奏+风噪）、收集（五声音阶拨弦，随连击升调）、受击（闷响）、翻船（落水）。默认开，首页可静音，设置存 localStorage
- **分享出口**：结算屏 Canvas 导出 → `writeTempFile` → `saveImageToPhotosAlbum` / `postNote`（标题「我在端午划了 XXXm」+ 图鉴进度 + tags）；未注入端能力时提示长按截图
- **无头测试钩子**：`window.__game` 暴露状态/分数/图鉴/注入事件（模拟滑动、点鼓、强制里程），供断言；种子随机（mulberry32）保证确定性
- **合规**：无内联脚本/行内事件（JS 外置 + addEventListener）；无剪贴板/下载/外链/传感器；全离线

## 5. 有意识的决策

1. **无尽而非关卡**：重玩性靠图鉴收集+称号+历史最佳，不靠关卡内容量（用户已选）
2. **翻船=3 点「稳」**：容错休闲向，不做一击即死
3. **知识点不做局内弹窗**：首次解锁只 toast 不打断节奏，全文在图鉴页与结算卡
4. **漩涡判定同礁石**：不做「吸入」物理，视觉差异化即可，控制实现复杂度
5. **不做跳跃/下蹲**：船在水面，换线+冲刺两键即全部操作
6. **称号阈值与难度数值为初版**：实现后按试玩手感调

## 6. 验收标准

- [ ] 第一里程碑：河面伪 3D + 龙舟可见且速度感成立（先过视觉关再堆内容）
- [ ] 换线/击鼓冲刺/受击/翻船全流程手感顺畅，中端机 60fps 无明显掉帧
- [ ] 生成器永不封死三航道（无头遍历断言）
- [ ] 图鉴 8 件解锁、持久化、知识卡全文可查，文案有据可查
- [ ] 结算屏 3:4 友好，存相册/发笔记按钮就位，无端能力时降级提示
- [ ] 无头全流程断言通过（开局→模拟滑行→收集→冲刺→翻船→结算→分享按钮）
- [ ] 过 `.skill` 全部自检清单，包体 <1MB

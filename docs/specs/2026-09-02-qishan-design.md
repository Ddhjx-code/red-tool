# 漆扇 · 设计文档

> 非遗手作坊系列第 17 作。自由创作型：用户自主设计漆纹，产出独一无二的漆扇。
> 创建日期：2026-09-02

## 1. 选题依据

- **趋势第一**：漆扇（漂漆扇）抖音投稿量 318 倍增长居榜首，小红书漆扇创作笔记点赞超 5 万，当前最热非遗。
- **形式定位**：自由创作型（非工序体验展示）。核心是「用户自主设计漆纹」，不是线性工序演示。
- **强分享属性**：每把扇子漆纹独一无二，成品晒图传播力强，符合系列「可分享」原则。

## 2. 文化准确性（调研结论）

- **漂漆/漂流漆**：大漆工艺技法之一，也称竜纹涂。大漆色漆调松节油/橘子油，轻质浮于水面，通过滴、点、弹、甩将色漆浮于水面，用笔/木棒在水中轻划产生肆意流变的纹样，再将器物下水漂出晾干。
- **大漆**：天然生漆，中国特有。8 年以上漆树可产漆，一棵一年约 500 克。调色加青金石、孔雀石、朱砂等天然矿物。
- **历史**：漆扇起源可追溯汉代，初为帝王仪仗。真正的非遗是「漆器髹饰技艺」，漆扇是大漆工艺结合现代审美的创新工艺。
- **核心魅力**："一半人为、一半天成"，入水速度/角度/摇晃方式决定纹路，无法复刻，独一无二。
- **配色参考**：敦煌配色、故宫配色、千里江山图配色；不易翻车：2 浅 1 深 或 2 暖 1 冷。

## 3. 核心机制：自主设计漆纹

用户全程主导创作，水面是画布，漆是颜料，用户是设计师。

### 创作控制点（4 个维度）

| 维度 | 用户控制 | 真实工艺对应 |
| --- | --- | --- |
| **漆色** | 选 2-4 种颜色（敦煌/故宫/千里江山/自定义调色盘） | 挑色 + 橘子油稀释 |
| **滴漆** | 点击水面任意位置滴漆，选颜色、控制滴量 | 滴管滴漆入水 |
| **拉纹** | 在水面拖动引导漆纹（流体交互），划出流云/波纹/漩涡 | 木棒点甩弹划拉纹 |
| **入水** | 选入水手法（垂直/旋转/Z 字），控制速度 | 扇子入水拓印 |

### 交互流程（自由创作，非线性）

1. **备水**：进入创作台，水面是空白画布（流体模拟）。
2. **选漆色**：从传统调色盘选 2-4 色（敦煌/故宫/千里江山/自定义）。
3. **滴漆 + 拉纹**（核心创作循环，可反复）：
   - 点击水面滴漆（选颜色 + 位置 + 滴量）。
   - 拖动水面引导漆纹（流体跟随指针流动，划出纹样）。
   - 漆在水面扩散、碰撞、交织，用户持续调整直到满意。
4. **入水拓印**：选入水手法（垂直/旋转/Z 字），扇面入水沾染漆纹。
5. **出水成品**：独一无二的漆扇呈现 + 知识卡 + 用户给作品起名（国风寓意名）。
6. **分享**：成品存相册 / 发笔记（postNote / saveImageToPhotosAlbum）。

### 关键设计原则

- **用户主导**：滴漆位置、拉纹手法、入水方式全由用户决定，没有固定脚本。
- **可反复创作**：不满意可重新滴漆/拉纹/换色，直到满意再入水。
- **随机性 + 可控性**：流体扩散有自然随机（"一半天成"），但用户通过滴漆/拉纹主导走向（"一半人为"）。
- **独一无二**：每把扇子纹路不可复刻，成品即作品。

## 4. 技术实现

### 流体模拟（核心）

- **WebGL 流体模拟**：漆色在水面扩散、流动、混合。参考 canvas-fx fluid/Liquid 组件（WebGL + GLSL），或自写简化 stable-fluids。
- **指针驱动**：用户拖动 = 虚拟指针驱动流体（拉纹）。
- **漆色渲染**：每种漆色是一种流体染料，滴入后在水面扩散，相互碰撞交织。
- **确定性**：种子化（mulberry32），保证可复现（用于 demo/录制）。

### 扇面拓印

- 扇面入水时，采样水面流体状态，转印到扇面形状（团扇/折扇）。
- 入水手法（垂直/旋转/Z 字）影响转印的纹路走向。
- 扇面形状可选：团扇（圆）/ 折扇（扇形）。

### 容器约束

- 离线 H5 zip，index.html 在根，禁内联脚本。
- WebGL 可用（容器规范允许 Canvas 2D / WebGL）。
- localStorage 存用户作品/进度。
- 包体 <2MB（流体引擎 + 扇面素材，无大图片依赖）。
- 成品出口走端能力 JS API（postNote / saveImageToPhotosAlbum / writeTempFile）。

## 5. 视觉与素材

- **程序化为主**：流体漆纹程序化生成，无需大图片素材。
- **扇面**：团扇/折扇轮廓（程序化绘制或简单 SVG）。
- **调色盘**：传统国风配色（敦煌矿物色/故宫红墙金瓦/千里江山青绿），程序化色卡。
- **背景**：水盆/水面氛围（程序化渐变 + 流体本身即视觉主体）。
- **可选生成图**：扇骨纹理/知识卡背景（wan2.7-image-pro，锁画风），但非必需。

## 6. 知识点（文化准确，有据可查）

- 漂漆技法：大漆工艺中的创新技法，漆不溶于水，浮于水面成纹。
- 大漆：天然生漆，漆树产漆，矿物调色，千年漆艺。
- 漆器髹饰技艺：真正的非遗（漆扇是其创新延伸）。
- 配色文化：敦煌/故宫/千里江山配色，国风色彩美学。
- "一半人为一半天成"：漂漆的不可复刻魅力。

## 7. 与系列的关系

- 第 17 作，自由创作型（继剪纸/水墨/敦煌拾色/霓裳羽衣之后）。
- 补「自主设计」缺口：用户主导创作，非工序展示。
- 复用：流体引擎（canvas-fx）、端能力分享（writeTempFile/postNote）、知识卡系统。

## 8. 技术选型决策（已定）

- **流体模拟**：WebGL 流体模拟 + 彩色染料（marbling/水拓效果，漂漆扇视觉本质）。指针 splat = 滴漆（注入染料 + 速度），拖动 advect = 拉纹（引导流向）。改造 canvas-fx 流体引擎为染料渲染，或经典 PavelDoGreat 式单文件流体模拟。**关键：染料渲染，非 DOM 捕获**（避开 B类实验 API 依赖）。
- **扇面形状**：团扇（圆）为主，折扇（扇形）可选。
- **调色盘**：固定传统配色（敦煌/故宫/千里江山）+ 用户自定义调色。
- **素材**：纯程序化为主（流体漆纹即视觉主体），扇面轮廓程序化/SVG，无大图片依赖；生成图仅用于知识卡背景（可选，非必需）。

## 9. 实施计划（prototype-first，规避打铁花视觉翻车）

1. **流体原型验证**（关键风险点）：先做最小 WebGL 流体染料原型，验证漆在水面扩散/拉纹的视觉是否达标（像漂漆扇，不像打铁花翻车）。✅ 已验证通过（用户确认「挺好，不错」），原型参数锁定不得回退。
2. 原型达标 → 完整实现：选漆色 → 滴漆/拉纹创作循环 → 入水拓印 → 成品 + 知识卡 + 起名 + 分享。
3. 冒烟测试 + 打包 dist/qishan.zip + 发布素材。

## 10. 设计系统（实现契约，先于代码）

系列视觉语言：国风、楷体、深色雅致。漆扇以「水盆夜色 + 宣纸金」为基调，所有颜色 / 间距 / 字号 / 圆角 / 动效必须取自 `assets/style.css` `:root` token，组件内不得出现魔法数字。

### 10.1 颜色 token

| token | 值 | 用途 |
| --- | --- | --- |
| `--water-deep` / `--water-mid` / `--water-glow` | `#060b12` / `#0a1320` / `#123047` | 水盆夜色背景、渐变、水体高光 |
| `--paper` / `--paper-dim` / `--paper-faint` | `#f3e9d2` / 62% / 34% | 宣纸主文字、次要文字、弱文字 |
| `--gold` / `--gold-soft` / `--gold-faint` | `#d9a62e` / 55% / 16% | 金强调、描边、底纹 |
| `--cinnabar` / `--cinnabar-soft` | `#e23d28` / 35% | 朱砂印章、主按钮、品牌 seal |
| `--silk` / `--wood` | `#f6efdd` / `#6b4a2f` | 扇面绢底、扇骨木色 |
| `--panel` / `--panel-solid` / `--line` / `--line-strong` | 46% 夜底 / `#0b1119` / 12% / 22% | 面板玻璃底、分隔线 |

漆色八种（程序化色卡，原型已验证，hex 锁定）：朱砂红 `#E23D28`、石青 `#2A6FD6`、石绿 `#15A67A`、藤黄 `#EFA81C`、黛青 `#2C6E86`、胭脂粉 `#D2567E`、墨黑 `#16181D`、金 `#D9A62E`。

### 10.2 间距 / 字号 / 圆角 / 动效

- 间距：4px 基准 `--sp-1..--sp-7`（4 / 8 / 12 / 16 / 24 / 32 / 48）。
- 字号：`--fs-2xs 10` → `--fs-title 38`（10 / 11 / 12.5 / 14 / 16 / 20 / 26 / 38）。
- 圆角：`--r-sm 6` / `--r-md 10` / `--r-lg 18` / `--r-pill 999`。
- 动效：`--ease cubic-bezier(.22,.61,.36,1)`，时长 `--dur-1 .16s` / `--dur-2 .28s` / `--dur-3 .5s`；只动 `transform` / `opacity` / `filter`，`prefers-reduced-motion` 降级。

### 10.3 字体

`--font: "Kaiti SC","STKaiti","KaiTi",…serif`（楷体，系统字体，无外部字体依赖）。

### 10.4 流体参数（锁定，不得回退）

`DENSITY_DISSIPATION 0.04`、`VELOCITY_DISSIPATION 0.34`、`CURL 30`、`SPLAT_FORCE 5200`、`TAP_FORCE 1400`、`COLOR_INTENSITY 1.25`、display shader 的 chroma-aware brightness（薄漆提亮到本色饱和、低彩度墨黑保原色）与 sheen 项，全部原样保留。

### 10.5 扇面与拓印

- 团扇：圆面 + 木柄；折扇：扇形 + 扇骨 + 轴铆。程序化 Canvas 绘制，无图片素材。
- 拓印：采样 dye 场 → RGBA8 捕获 → 按入水手法做 UV warp（垂直＝整体直拓、旋转＝绕心涡卷、Z 字＝分段带状）→ 双线性采样 → 贴到扇形。
- 分享卡：900×1200 国风构图（扇 + 名 + 知识 + 印章），Canvas 2D 程序化绘制。

## 1. 产品流程

```
首页（选折法 × 选模式）→ 剪裁台 → 点「展开」→ 逐层展折动画 → 成品页（换底+知识卡+截图）
```

## 2. 折法模型

折法 = 楔形角度 + 展开份数（二面体对称 D_n）：

| 折法 | 楔形角 | 份数 | 展开动画节奏 |
| --- | --- | --- | --- |
| 四折 | 90° | 4 | 2 次翻折（1→2→4） |
| 五折 | 36° | 10 | 镜像翻开 → 5 瓣扇形绽放 |
| 六折 | 30° | 12 | 镜像翻开 → 6 瓣扇形绽放 |
| 八折（默认） | 45° | 8 | 3 次翻折（1→2→4→8） |

对称渲染：份数 = 2n 时，楔形副本按 `k * wedgeAngle` 旋转、交替镜像排布。

## 3. 剪裁台（手动模式）

- 折纸以楔形呈现：白宣纸色 + 程序化微纹理；折痕边实线 + 「×N 层」层叠纸边暗示；开口边虚线
- 触摸即剪：`destination-out` 圆形笔刷沿 pointer 轨迹插值盖章（间距 = 半径×0.4），剪裁层为 1024px offscreen canvas，裁剪到楔形扇区内
- 笔刷 3 档：细剪 / 中 / 粗（半径 10/18/30）
- 工具：重折一张（清空）、预览开关（角落实时渲染完整对称小样，默认关）
- 交互用 Pointer Events（PC 模拟器鼠标与真机触摸统一）

## 4. 逐层展折动画（方案 A，核心体验）

按真实折剪法的物理结构生成「翻折剧本」，每种折法展开方式不同：

| 折法 | 真实折法 | 展开剧本 |
| --- | --- | --- |
| 四折 | 对折×2 | 翻倍翻开 → 沿直径大翻（2 翻） |
| 八折 | 对折×3 | 翻倍翻开 ×3（楔→方→半圆→全圆） |
| 六折 | 对折 + 折三折（60° 锥） | 锥体翻开 → 两片手风琴式卷开 → 半圆沿直径大翻（4 翻） |
| 五折 | 对折 + 折五折（36° 锥） | 纸卷逐片卷开 ×4 成半圆 → 沿直径大翻（5 翻） |

- 每一翻：flap 副本组绕折痕线做 3D 翻页的 2D 投影——垂直折痕方向缩放 `cos(φ)`，φ 0→π，easeInOut 缓动，翻动中轻微变暗
- 每翻间隔 ~210ms，单翻 620ms；点按可跳过
- 收尾：整体 scale 微弹定格 → 背景渐变成品底色 → 知识卡浮现

## 5. 模板模式

- 模板 = 楔形局部坐标系（顶点为原点、半径归一化 0-1）内的闭合剪裁路径，存于包内 JS 数据
- 描剪：楔形上叠加淡灰引导线，跟着剪
- 一键成剪：剪刀点沿路径自动走剪裁动画 → 直接进入展开
- 首批 4 个：团花（八折）、梅花（五折）、窗花（六折）、囍（四折）

## 6. 成品页

- 底色三选：红纸窗花（暖光窗棂底 + 红纸）、白宣（朱红底 + 白纸）、夜景（深蓝夜空 + 灯笼光晕 + 红纸发光）
- 纸张染色：剪裁层副本经 `source-in` 合成染色后绘制
- 知识卡：剪纸冷知识随机一条（国家级非遗、2009 联合国教科文组织人类非遗代表作名录等）
- 按钮：再剪一张 / 换折法 / 换模板

## 7. 技术结构

```
tools/jianzhi/
├── index.html          # 入口（容器模板）
└── assets/
    ├── style.css
    ├── templates.js    # 模板路径数据
    ├── paper.js        # 剪裁层 + 笔刷 + 对称渲染
    ├── unfold.js       # 展折动画引擎
    └── main.js         # 视图切换 + 应用编排
```

- 原生 JS 无依赖；脚本加载顺序：templates → paper → unfold → main
- 单 canvas 主渲染 + offscreen 剪裁层；视图切换用 DOM class
- 预计包体 <300KB

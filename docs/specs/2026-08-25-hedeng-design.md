## 0. 产品定义

| 项 | 结论 |
| --- | --- |
| 情感定位 | 「中元不是鬼节，是思念的节日」——温柔重构叙事（调研验证：重述神话笔记评论区高共鸣） |

## 1. 流程（一次 ~40 秒）

```
首页（中元背景+温柔重构文案）→ 选灯 → 写灯 → 点灯 → 放灯 → 结果卡 →(再放一盏 | 灯谱)
```

| 幕 | 互动 | 产出 |
| --- | --- | --- |
| 1 选灯 | 三选一：荷灯（寄亲人）/ 船灯（寄远行）/ 桃灯（寄平安） | 灯型决定结果卡灯形与断语 |
| 2 写灯 | 选寄给谁（逝去的亲人/毛孩子/老朋友/过去的自己）+ 写一句话（≤20字，可留空用默认句） | 文字进结果卡 |
| 3 点灯 | 长按点火苗，火苗随按住时长长大（1.5s 点满），松手早则火苗小 | 心念值（火苗大小）影响结果卡品级 |
| 4 放灯 | 灯入水，顺夜河漂远；别人的灯（种子生成 8-12 盏）交错漂过；水声虫鸣 | 治愈高光时刻 |
| 5 结果 | 结果卡 + 知识卡 | 分享出口 |

## 2. 结果系统

- 结果卡 900×1200：黛青夜河 + 你的灯（大图）+ 竖排手写句 + 寄给谁 + 品级印章（心念满=「灯明」/中=「灯暖」/小=「灯微」，无负面）+ 底部「一盏河灯 · 中元」
- 灯谱（收集）：3 灯型 × 4 寄对象 = 12 组合，点亮过的在灯谱里显示（重放动机）
- 知识卡 3 条（发布前复核）：
  1. 中元节源于上古秋尝祭祖，道教称「三元」之地官赦罪日，佛教盂兰盆节同期——三俗合流而成今日中元
  2. 放河灯（放荷灯）是中元旧俗：《梦粱录》载南宋临安中元「差内侍往江中放灯」，灯以纸为荷花形，寓「照冥引路」，今扬州大明寺等地仍有水灯会
  3. 河灯漂得远、灯不灭，旧俗以为吉兆——「谁的灯先灭，谁的思念先靠岸」为今人演绎，非古俗（标注清楚）

## 4. 技术

- 架构复用乞巧局：IIFE + window.HD* 全局；Canvas 2D 场景 + DOM 视图
- 模块：data.js / rng.js（mulberry32）/ scene.js（夜河+灯+漂灯动画）/ audio.js（程序化：水声滤波噪声+虫鸣+点火+古琴结果音）/ save.js（灯谱 localStorage）/ share.js（结果卡+端能力判空降级）/ main.js
- 无头钩子：?test=1 + window.__game；?demo=1 自驾
- 合规：容器规范同系列

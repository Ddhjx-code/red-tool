# 文物修复局 v1 设计文档

- 日期：2026-08-14
- 系列：「非遗手作坊」M3（打铁花搁置后的接续）
- 形式：解谜拼合型（series-plan §3 形式分类）
- 素材源：大都会博物馆开放 API（CC0 公有领域 + 高清原图，通道已验证 2026-08-14）

---

## 0. 产品定义

| 项目 | 结论 |
| --- | --- |
| 面向谁 | 小红书国风/文博兴趣用户，随手点开的 casual 玩家 |
| 提供什么 | 3-5 分钟「亲手修复一件文物」：形→色→魂层层修出，落定一张可晒的修复报告 |
| 用来干什么 | 修复的成就感 + 截图分享 + 修出来的知识（不是贴上去的） |
| 视觉策略 | **文物真照片是主角**（馆藏摄影保证视觉质量），UI 用系列共享 tokens；吸取打铁花教训——不拿程序化视觉硬撑场面 |

## 1. 核心循环（用户确认：3 件 × 完整四层）

一件文物 = 一段修复旅程：

| 层 | 玩法 | 交互 | 揭示 |
| --- | --- | --- | --- |
| 形 · 清理拼合 | 9-12 块不规则碎片拖拽归位，靠近吸附锁定 | 拖拽 | 器物轮廓 |
| 色 · 色彩还原 | 拼好的器物蒙浮土/锈蚀层，手指拂拭透出原色，≥85% 自动完成 | 拂拭（destination-out 笔刷，剪纸同款） | 器物本来的颜色 |
| 魂 · 纹样推理 | 放大一处纹样，三选一推理；答错轻晃可重试，答对引出知识 | 点选 | 纹样背后的时代 |
| 成 · 修复报告 | 完整器物 + 名称/年代/馆藏 + 知识 + 落款「再修一件」 | 落定 | 截图分享时刻（3:4 友好） |

入口：三件文物选择（各一件缩略图 + 名称），修复完成打勾。

## 2. 三件文物（素材要求）

| 类别 | 要求 | 色彩还原看点 | 纹样推理考点 |
| --- | --- | --- | --- |
| 青铜礼器 | 商周，饕餮/夔龙纹清晰，CC0 高清图 | 青铜原为金色，绿锈是千年痕迹 | 饕餮纹：礼器通神的威仪 |
| 瓷器 | 纹样清晰（龙纹/缠枝等） | 釉色透出 | 纹样的等级/寓意 |
| 唐三彩 | 骆驼/马/俑，三彩釉色鲜明 | 黄绿褐三彩显现 | 三彩是冥器/丝路见证 |

素材纪律：只用 `isPublicDomain=true`；下载后本地转 webp（~800px，≤250KB/张）；纹样局部从原图裁切；metadata（名称/年代/馆藏）直接取 API 字段，知识文案需有据可查。

## 3. 技术实现

- Canvas 2D + DOM/CSS 混合：文字/UI/报告全 DOM，拼合与拂拭走 Canvas
- 碎片生成：种子随机（mulberry32）网格扰动切线 → 不规则四边形块；点内判定拾取；吸附距离阈值 ~24px，锁定后不可再动
- 拂拭还原：离屏 canvas 盖「土锈层」（去饱和+土色叠加），destination-out 圆形笔刷擦除；每 N 帧采样剩余 alpha 估进度
- 推理题：包内 JSON（纹样裁切区域 + 题干 + 三选项 + 答案 + 知识文案）
- 状态机：select → assemble → color → quiz → report → (下一件 | 重选)
- localStorage：记录已完成文物（容器允许）
- 确定性：全部种子随机，无头可断言

## 4. 有意识的决策（用户已审）

1. **馆藏表述中性**：只陈述事实（藏于大都会博物馆），不打"流失海外"情绪牌
2. **难度偏休闲**：淡轮廓提示 + 吸附宽容 + 答错无惩罚
3. **拼合只拖拽不带旋转**（v1 手感优先，旋转是 v2 进阶项）

## 5. 验收标准

- [ ] 3 件文物 × 四层全流程可玩
- [ ] 碎片吸附手感顺滑（无头拖拽测试通过）
- [ ] 拂拭进度检测准确，完成有反馈
- [ ] 推理题答案正确、知识有据
- [ ] 报告屏截图友好（3:4）
- [ ] 包体 <2MB，过 .skill 自检清单

## 6. 实现顺序

素材落地（选件+下载+压缩+裁切）→ 拼合 → 拂拭 → 推理 → 报告 → 无头断言 → 打包

# 糖球转转 设计文档

- 日期：2026-11-17
- 系列外第二组：「可爱风 · 幸存者类」（survivor-like / 割草 roguelite）
- 品类参考：《吸血鬼幸存者》《弹壳特攻队》《土豆兄弟》——共同循环＝中心角色 + 四面八方涌怪 + 武器自动开火（含绕身环绕类） + 击杀掉经验/武器 + 升级三选一
- 题材基调：用户定的「暖暖式可爱」——粉彩、圆润、亮片星屑、无恐怖元素；血条换成「心心」
- 素材：零外部素材，全程序化（Canvas 2D + 手绘式圆角图形 + WebAudio）
- 工作名：糖球转转（备选：别碰我的糖 / 糖糖不打烊）；目录 `tools/tangqiu`，产物 `dist/tangqiu.zip`
- 类目：`casual_game`；`is_high_consumption_scene: false`

---

## 0. 产品定义

| 项目 | 结论 |
| --- | --- |
| 面向谁 | 小红书女性向休闲用户 + 学生党；「可爱画风 + 3 分钟一局」是停留与复玩的双钩子 |
| 提供什么 | 3 分钟一局的自动战斗生存：拖摇杆躲怪，糖针绕身自动打，攒糖升级换武器，活到天亮 |
| 用来干什么 | 局内爽感（怪越多越爽）+ 局外晒图（存活时长/称号/武器组合卡） |
| 核心差异 | 现有序列里唯一「高爽感动作」品类；可爱外皮 + 环绕武器组合（build）深度，和《词兽守夜》的慢节奏拼词形成互补 |
| 不做 | 不做手动瞄准/手动攻击（单手原则）；不做装备养成与关卡地图；不做联网排行榜 |

## 1. 核心循环

```
走位躲怪 → 环绕武器自动输出 → 怪死掉糖果 → 拾糖升级 → 三选一（新武器 / 升武器 / 加属性）
   ↑                                                                    ↓
   └───────────────── 更强的输出 → 更多怪 → 更多糖 ←────────────────────┘
```

- 一局 180 秒，难度随时间单调上升，不设关卡。
- 玩家唯一操作：**摇杆走位**（左下角，跟手；屏幕任意处按下也算摇杆，单手可玩）。
- 死亡或撑满 180 秒进入结算；结算卡可存相册 / 发笔记。

## 2. 操作与手感

| 项 | 规格 |
| --- | --- |
| 摇杆 | 基座半径 46u，摇杆头 22u，摇杆头位移上限 34u；死区 4u；输出为归一化向量 × 移速 |
| 移速 | 基础 96u/s；摇杆满推即满速（不做非线性曲线，避免滑手） |
| 触摸区 | 左下 60% 屏宽、下半屏；落点即基座中心（浮动摇杆），松手归位 |
| 无敌帧 | 受击后 1.0s 闪烁无敌，避免贴脸连掉心 |
| 顿帧 | 升级与受击各 60ms 轻微顿帧，给打击感 |

## 3. 数值

| 项 | 初始 | 说明 |
| --- | --- | --- |
| 心心 | 5 | 每次接触 -1，受击后无敌 1s；无回复道具（升级可选 +1 心，上限 8） |
| 经验 | 每颗糖 1 点 | 阈值 = 5 + level × 3（Lv1→2 需 8，之后递增） |
| 武器位 | 2 个起，上限 4 | 满了以后新武器从池中剔除，只出升级项 |
| 同屏怪上限 | 90 | 超限不再生成，防低端机掉帧 |

## 4. 武器表（环绕 orbit 为主，兑现「武器绕着人转」）

| 武器 | 类型 | 初始 | 每级增益 | 手感要点 |
| --- | --- | --- | --- | --- |
| 星星糖针 | 环绕 orbit | 2 根，半径 52u，转速 2.2 rad/s，伤害 4 | +1 根 / 半径 +7u / 伤害 +2 | 默认武器，命中带击退与星屑 |
| 猫爪环 | 环绕 orbit（反向） | 1 环，半径 78u，伤害 6 | +1 环 / 伤害 +3 | 与糖针反向转，交叉区形成「绞肉带」 |
| 彩虹弹 | 发射 shooter | 0.9s/发，伤害 5，自动瞄最近 | 攻速 +25% / 弹数 +1（散射 ±12°） | 唯一远程，补足外圈 |
| 泡泡糖 | 光环 aura | 0.55s 一次，半径 66u，伤害 3 | 半径 +12u / 伤害 +2 | 近身保险，破围用 |
| 糖霜落雨 | 定点 AoE | 1.6s 一次，落点随机取怪，伤害 8，半径 40u | 次数 +1 / 伤害 +4 | 视觉最响，专治后排蝙蝠 |

升级池权重：已有武器 45% / 新武器 30% / 属性 25%（属性：伤害 +10%、攻速 +12%、移速 +8%、拾取半径 +20%、+1 心）。

## 5. 敌人表

| 敌人 | 外形 | HP | 移速 | 出现时间 | 行为 |
| --- | --- | --- | --- | --- | --- |
| 布丁怪 | 焦糖布丁色圆角方块，抖 | 3 | 26u/s | 0s | 直线逼近 |
| 果冻怪 | 薄荷半透明，弹性缩放 | 6 | 34u/s | 20s | 直线，被击退更远 |
| 棉花糖蝠 | 淡紫双翼，左右摆 | 2 | 68u/s | 45s | 高速冲刺，脆 |
| 蛋糕卫兵 | 粉奶油塔，慢 | 26 | 18u/s | 75s | 大体积，击退抗性 |
| 大蛋糕 BOSS | 三层蛋糕 + 蜡烛 | 260 | 14u/s | 160s | 每 2.5s 召唤 3 只布丁怪 |

生成：贴屏幕外缘随机点，每 0.85s 一批，数量 = 1 + floor(t/25)，血量随 t 线性 ×(1 + t/150)。

## 6. 画面（可爱风落地规则）

- 色板：奶油底 `#FFF6F2`、蜜桃 `#FFC2D1`、薄荷 `#B8EBD9`、淡紫 `#D9CDF6`、奶黄 `#FFE3A3`、文字深棕 `#5B4B4B`
- 一切形状圆角 ≥ 30% 半径；描边统一 3u 深棕，比纯色块更像手绘贴纸
- 星屑/小心心粒子承担「爽感」，击杀炸 5 颗；暴击不显示数字，改闪白
- 背景：极淡斜格纹 + 边缘柔光，不抢主体
- 中文字一律 DOM（Canvas 里中文发虚），Canvas 只画图形与英文/数字

## 7. 技术方案

| 项 | 结论 |
| --- | --- |
| 渲染 | 单 Canvas 2D，DPR ≤ 2，逻辑坐标 = CSS px，主循环 rAF + dt 钳制 33ms |
| 图层 | Canvas 画场地/敌人/武器/粒子；DOM 画 HUD、摇杆、升级面板、结算卡（中文可读） |
| 碰撞 | 圆-圆，O(n·m)，n ≤ 90、m ≤ 12，单帧上限 ~1000 次判定，够用 |
| 音频 | WebAudio 程序化：拾糖（短促三角波）、命中（噪声爆）、升级（上行三音）、受击（低频闷响）、BOSS（低鸣） |
| 存档 | localStorage 记最高存活时长与最佳击杀（单 key < 1KB） |
| 分享 | `writeTempFile` → `saveImageToPhotosAlbum` / `postNote`，`window.xhs?.miniTool` 判空降级为提示 |
| 兼容 | Chrome 61 / ES2017：`var` + `function` 为主，不用可选链、对象展开、`flat`、`at`、`replaceAll`；CSS 不用 gap/inset/clamp/`:is()` |
| 体积 | 源码目标 < 60KB（3 个文件），零位图，zip < 20KB |

## 8. 里程碑

| 阶段 | 交付 | 验收 |
| --- | --- | --- |
| M1 竖切 | 摇杆 + 1 环绕武器 + 2 种怪 + 掉糖 + 升级三选一 + 计时 | 手机单手能连续玩 60s 不误触，装置不卡 |

## 9. 风险与对策

| 风险 | 判断 | 对策 |
| --- | --- | --- |
| 低端机 90 只怪掉帧 | 中 | 同屏上限 90 + 粒子上限 240 + DPR 上限 2 + 帧率低于 45 时自动减粒子 |
| 环绕武器「看着爽、打着空」 | 中 | 环绕半径与怪体积对齐（半径 52u 覆盖贴身圈），命中即击退，给出明确反馈 |
| 3 分钟太长，小红书用户耐心短 | 中 | 前 20s 就给到「怪涌上来 + 第一次升级」，10s 内必有正反馈 |
| 可爱画风显得「不像游戏」 | 低 | 靠密度与动效承担游戏感：受击缩放、星屑、震屏 |
| 与《词兽守夜》撞车 | 低 | 一个慢思考、一个快反应；文案里做「同作者双开」的系列感 |

## 10. 已定与留待

已定（2026-11-17 实现时拍板）：

1. 名字：**糖球转转**（备选「别碰我的糖」「糖糖不打烊」留作后续活动名）
2. 初始武器固定为「星星糖针」，不做随机起手——首局要让玩家 3 秒看懂玩法
3. BOSS 一阶段 + 召唤小怪，不做三阶段换外观（省体积，靠血条与召唤量撑场面）

留待真人试玩后决定：

1. 是否需要「每局随机初始武器」增加 roguelite 复玩性
2. 是否把 5 心改成 3 心（现在按机器人满速躲，180 秒只掉 1-4 心，偏宽松）
3. 是否加一个「每 30 秒来一波精英」的中期节奏点

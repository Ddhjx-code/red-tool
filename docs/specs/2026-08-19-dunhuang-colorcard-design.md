# 敦煌拾色 设计文档

- 日期：2026-08-19
- 系列：「非遗手作坊」#10
- 形式：自由创作型（色彩提取 + 色卡拼合），系列首个「色彩美学」方向
- 调研依据：敦煌矿物色为史实（石青/石绿/朱砂/雌黄/铅白等均有矿物学出处）；壁画用**风格化插画**呈现（用户已确认，规避真实壁画版权）
- 素材：零外部素材，全程序化（壁画为矢量色块插画）

## 0. 产品定义

| 项目 | 结论 |
| --- | --- |
| 面向谁 | 小红书色彩/美学/国风兴趣用户，配色卡内容天然吃香 |
| 提供什么 | 从风格化敦煌壁画里「提取」矿物色，集进色谱图鉴，自选版式/底色/题字拼一张专属敦煌色卡 |
| 用来干什么 | 提色的探索乐趣 + 集色的收集欲 + 拼卡的创作表达 + 色卡晒图传播 |
| 核心差异 | 系列首个色彩美学工具；成品色卡人手一张不重样（版式×底色×选色×题字组合） |

用户已确认：风格化壁画呈现；成品卡**立轴色谱 + 藻井两种版式都保留、可自选**；提色为**放松探索式**（点按提取 + 隐藏色 + 蒙尘擦拭，无压力）。

## 1. 核心循环（一局 2-3 分钟）

```
首页 → 选壁画 → 提色（探索）→ 拼色卡 → 成品卡（分享）
                ↘ 色谱图鉴（收集进度）↗
```

| 幕 | 互动 | 产出 |
| --- | --- | --- |
| 1 选壁画 | 3 幅风格化壁画选 1：飞天 / 九色鹿 / 藻井 | 进入提色 |
| 2 提色 | 点按色块提取（颜色飞入调色盘 + 弹色名/来历）；找**隐藏色**；擦**蒙尘色** | 解锁矿物色入图鉴 |
| 3 拼色卡 | 挑 3-6 色 → 选版式（立轴色谱/藻井）→ 选底（宣纸/绢本/夜空）→ 选题字 → 钤印 | 实时预览色卡 |
| 4 成品 | 色卡落定，高光动效 | 存相册 / 发笔记 |

## 2. 内容：3 壁画 × 18 矿物色

### 2.1 壁画（风格化矢量插画，色块清晰可点按）

| 壁画 | 时代 | 画面 | 色系 |
| --- | --- | --- | --- |
| 飞天 | 盛唐 | 天空+流云+飞天飘带+光环 | 石青/花青天空，朱砂/胭脂/藤黄飘带，铅白飞天，金光环 |
| 九色鹿 | 北魏 | 山峦+河+九色鹿+草木 | 赭石/黄赭鹿身，石绿/竹青山峦，石青河，朱砂点缀 |

- 隐藏色（每壁画 1-2 个）：藏在细节（金在飘带/光环、天蓝在天空一角），找到弹「发现隐藏色」
- 蒙尘色（每壁画 1-2 个）：被浮尘盖住，**擦除显色**（destination-out，复用剪纸/文物手感）

## 3. 提色玩法细节（放松探索式）

- **点按提取**：点中色块 → 该色一块「飞入」右下角调色盘（抛物线动画）+ 顶部弹色名卡（名 + 一句来历）+ 轻音效。已解锁色再提取也飞入（补充可用），不重复弹知识
- **隐藏色**：外观与普通色块无异，点中才知是隐藏色 → 金色粒子 + 「发现隐藏色 · {名}」
- **蒙尘色**：色块上盖一层「浮尘」（土色半透明层），手指擦拭露出原色，擦净 ≥85% 自动提取 + 「拂尘见色 · {名}」
- **无失败、无计时、无次数限制**——纯放松，集齐靠探索
- 壁画内可双指/按钮切换「原图 / 已提色标记」（已提过的色块描边示意，防重复找）

## 4. 拼色卡（成品，核心卖点）

- **选色**：从已解锁色里挑（立轴色谱 3-6 色；藻井固定 5-6 层）
- **版式**（两选一，均可用）：
  - **立轴色谱**：竖条并排，色名竖排其下（视觉稿 A）
  - **藻井**：同心方井旋转套叠 + 圆形色点图例（视觉稿 B）
- **底色**：宣纸 #F5F0E6 / 绢本（暖绢 #EFE6D2）/ 夜空（黛青 #2E3D52，字转月白）
- **题字**：预设若干（「飞天遗色」「鹿王本生」「藻井五色」「敦煌拾色」+ 按来源壁画自动推荐），可选；钤印固定「敦煌」朱印
- **实时预览**：拼卡过程即所见即所得；点「成卡」落定 + 钤印盖落动效
- 成品卡 900×1200，Canvas 绘制 → writeTempFile → 存相册/发笔记（同乞巧那套）

- 架构沿用系列：IIFE 模块 + `window.DH*` 全局；Canvas 2D（壁画/提色动效/色卡）+ DOM 视图

## 7. 知识点（知识卡轮换）

1. 敦煌壁画颜料以矿物色为主：石青（蓝铜矿）、石绿（孔雀石）、朱砂（硫化汞）等，历千年而色不褪
2. 部分颜料会随时间变色：铅白遇硫发黑、铅丹氧化褐变——今天看到的敦煌色，已非画工当年所见
3. 「丹青」即指绘画：丹为朱砂、青为石青，古人以主要颜料代指绘画
4. 敦煌莫高窟 1987 年列入世界文化遗产，现存壁画约 4.5 万平方米
5. 矿物色研磨分粗细：粗者颗粒闪光、细者匀净，画工分层叠加成「厚色」

## 8. 有意识的决策

1. **风格化壁画而非真实照片**：规避版权，且 flat 色块更利「点按提色」玩法（用户已确认）
2. **放松探索式提色**：无失败/计时/次数，精致手感优先（用户已确认）
3. **两种色卡版式都保留可自选**：丰富度优先（用户已确认）
4. **壁画是视觉风险点**：飞天/九色鹿为造型插画，需先出视觉检查点确认「精致」达标再堆内容（打铁花教训）；藻井为几何纹样最稳，先行
5. **题字用预设不用自由输入**：v1 控范围、保美感，自由输入留 v2

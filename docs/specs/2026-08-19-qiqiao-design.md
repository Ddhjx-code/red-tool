## 0. 产品定义

| 项目 | 结论 |
| --- | --- |
| 面向谁 | 小红书测试/占卜类内容消费者（结果卡自带晒图属性），国风兴趣用户 |
| 提供什么 | 40 秒「丢针试巧」仪式：舀水→定心→投针→显影，占出 300 种不重样的巧运解读 |
| 用来干什么 | 占卜结果晒图（测试类传播逻辑）+ 影形图鉴收集 + 修出来的知识 |
| 核心差异 | 结果系统是产品本体：影形×面向×品级组合拼装，不是平铺几条签文 |

用户已确认：占卜/测试类 + 一点点玩法；**结果要多样、有解释性，不能来来去去就几个**。

## 1. 结果系统（核心）

三层组合，卡片文案现场拼装：

| 层 | 数量 | 内容 |
| --- | --- | --- |
| 针影（影形） | 12 | 10 吉 + 2 未得巧，全部可回溯「针影如某物」史料占法 |
| 巧运面向 | 5 | 针工 · 文采 · 姻缘 · 家宅 · 财市 |
| 品级 | 5 | 上上巧 · 上巧 · 中巧 · 小巧 · 未得巧 |

组合数 12×5×5 = **300 种**；实际只写 22 段断语（影形断语 12 + 面向断语 5 + 品级断语 5），卡片 = 影形名/图 + 品级印章 + 面向 + 三段断语拼装 + 知识卡。

### 1.2 抽取规则

- **影形**：种子随机加权抽取（吉影权重高；槌/烛各约 7%，合计 ~14% 保留张力）；图鉴未解锁影形权重 ×1.5（收集保底）
- **面向**：种子随机均权
- **品级**：由「心诚值」加权（见 §2 定心环节）——心诚值高则上上巧/上巧概率上升，低则未得巧概率上升；**概率偏移而非决定**，保持占卜感
- 同一玩家连续占：影形不连续重复（记录上次影形，重抽一次）

## 2. 流程与玩法（一次 ~40 秒）

```
首页 → 舀水 → 定心 → 投针 → 显影 → 结果卡 →(再占 | 图鉴 | 分享)
```

| 幕 | 互动 | 判定/产出 |
| --- | --- | --- |
| 1 舀水 | 长按木勺注水入盆（进度环 ~1.5s 注满） | 纯仪式，注满进入下一幕 |
| 2 定心 | 呼吸圈由大收小（~2.4s 一轮），收束到中心时松手 | 心诚值 = 100 - 偏差映射（0-100）；提前/太晚松手都扣分 |
| 3 投针 | 银针悬于水面轻晃，点按落下 | 针落涟漪动画；无判定（仪式感） |
| 4 显影 | 涟漪渐平、月光渐亮，盆底针影缓缓浮现（2.5-3s 悬念） | 显影动画逐帧揭示影形剪影 |
| 5 结果 | 结果卡落定 | 占卜卡 + 知识卡 + 分享出口 |

- 失败态：无（占卜类不设失败）；定心环节松手太早（圈还很大）= 心诚值低，仍继续流程
- 教学：首占浮层提示三步操作，之后不再出现

| UI | 顶部安全区；楷体标题栈；长按/松手操作用进度环与呼吸圈 |

## 4. 技术实现

- 架构沿用龙舟：IIFE 模块 + `window.QQ*` 全局；Canvas 2D（夜空/水盆/针/影）+ DOM 视图（首页/结果/图鉴）
- 模块：`data.js`（影形/断语/知识/常量）、`rng.js`（复用 mulberry32 实现）、`scene.js`（夜空+水盆+涟漪+显影）、`shadow.js`（12 影形矢量绘制）、`divine.js`（抽取/心诚值/结果状态机）、`audio.js`（WebAudio：注水/定心跳动/针落叮/显影磬声/结果钟）、`share.js`（结果卡+端能力）、`main.js`（装配）
- 状态机：`home → water → calm → drop → reveal → result`
- 存档 localStorage `qiqiao-save`：`{codex:[影形id], runs, lastShadow}`
- 分享：结果卡 Canvas 导出 → writeTempFile → saveImageToPhotosAlbum/postNote，判空降级截图提示
- 无头钩子：`?test=1` 固定种子 + `window.__game`（start/skipTo/setCalm/snapshot）；`?demo=1` 自动完整流程（发布素材用）
- 合规：容器规范同系列（外置脚本/无内联/无禁用 API/端能力判空）

## 6. 有意识的决策

1. **不做「一天只能占一次」**：图鉴收集需要重玩，限制会杀死收集动机
2. **投针环节无判定**：判定集中在定心一处，操作点少而准（占卜感 > 技巧感）
3. **未得巧保留 ~14%**：全吉无张力；措辞温和鼓励，不劝退
4. **影形 8→12**：史料 8 形（云/花/鸟/兽/鞋/剪/槌/烛）中「兽」形拆为凤凰/狸猫/玉龙三形，再增金鱼/莲花两形，成 10 吉影；槌/烛 2 个未得巧原样保留，共 12
5. **不做蜘蛛应巧/巧果**：v1 聚焦丢针一条线，其余习俗进知识卡

## 7. 验收标准

- [ ] 全流程闭环：舀水→定心→投针→显影→结果，40 秒内完成
- [ ] 结果多样性：300 组合拼装正确；连占 20 次影形不连续重复；心诚值高低品级分布差异可断言
- [ ] 显影动画有悬念感（涟漪平→月光亮→影渐显）
- [ ] 图鉴 12 影形收集、持久化、未解锁权重提升
- [ ] 结果卡 3:4 分享友好，存相册/发笔记按钮就位，无端能力降级
- [ ] 知识卡 5 条准确（引文按调研文档复核后）
- [ ] 无头全流程断言 + zip 冒烟；包体 <1MB

## 8. 实现顺序

1. 骨架 + data（影形/断语/知识）+ 夜空水盆场景 → **视觉检查点**
2. 三幕互动（舀水/定心/投针）+ 状态机
3. 显影动画 + 12 影形矢量
4. 结果系统（抽取/心诚值/拼装）+ 结果卡视图
5. 图鉴 + 存档 + 分享出口
6. 音效 + 教学 + 打磨
7. 无头断言 + 打包 + series-plan 更新
8. 发布素材（demo 录屏/截图/文案）

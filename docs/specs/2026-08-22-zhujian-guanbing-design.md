# 竹简观兵 设计文档

- 日期：2026-08-22
- 系列：「非遗手作坊」#13
- 形式：展示型（3D 展卷 · 文博向）——延续「文物修复局」的展示类别，但交互本体是「展卷」而非「修复」
- 选题：山东博物馆 · 银雀山汉墓竹简《孙子兵法》（1972 年临沂银雀山出土，十三篇俱全，现存最早的《孙子》写本）
- 素材：零外部素材，全程序化（three.js 内嵌，复用 `tools/wenwu/assets/vendor/three.min.js`，603KB）
- 工作名：竹简观兵（备选：银雀论兵）；目录 `tools/zhujian`，产物 `dist/zhujian.zip`

---

## 0. 产品定义

| 项目 | 结论 |
| --- | --- |
| 面向谁 | 文博/历史兴趣的小红书用户 + 军迷 + 国风人群交叉；借「狂飙热梗/武经之首」话题度 |
| 提供什么 | 60 秒「3D 展卷」仪式：一捆卷起的汉简在暗室灯光下徐徐展开，十三篇平铺展台上，逐篇读简、摘金句 |
| 用来干什么 | 「亲手打开一件国宝」的仪式感 + 金句手记晒图 + 十三篇收集（图鉴） |
| 核心差异 | 不修文物、不答题，纯「展示」：3D 物感 + 光场氛围是本体；文本是《孙子兵法》十三篇原文金句，天然自带传播 |
| 不做 | 不做战斗/策略玩法、不做修复解谜、不做大段科普阅读；知识全部折叠进「附片」，一卡一小点 |

用户已确认：**十三篇全展示**（不做精选阉割）；3D 化优先。

## 1. 展示系统（核心）

### 1.1 三层结构：卷 → 束 → 简

| 层 | 形态 | 说明 |
| --- | --- | --- |
| 卷 | 开场：一捆卷着的竹简横置展台，可 360° 旋转 | 主视觉即「待开之物」，留悬念 |
| 束 | 展卷后：十三篇，每篇一束，自右向左平铺（古书右起） | 篇签（竖排篇名+篇次）浮于束上 |
| 简 | 读篇：每篇 3 枚示意简立起放大 | 篇题简 / 金句简 / 今译·点睛简 |

### 1.3 出土与本体知识（首页脚注 + 图鉴 + 全卷解锁页）

- 1972 年 4 月，山东临沂银雀山一、二号西汉墓出土大批竹简；一号墓 4,942 枚，二号墓 32 枚（总数口径待核）
- 主要入藏山东省博物馆；部分存临沂等地文博单位（归属口径待核）
- 同墓出土失传近两千年的《孙膑兵法》，与《孙子兵法》同出，「孙武≠孙膑」千年悬案得证
- 简本十三篇俱全，结构同今本；简本篇题多单字（如《形》《势》），今本作《军形》《兵势》；第十三篇简本作《用閒》
- 现有最早的《孙子》写本；汉代隶书，细竹条编册
- 山东博物馆 2025 年举办「银雀山汉简文化展」
- 《武经七书》之首；1772 年法译本为最早西译（待核）

## 2. 流程与交互

状态机：`home → stage(idle) → unroll → browse → read(篇/枚) → note(手记)`；`codex(图鉴)` 从 home / stage 常驻入口进入

| 幕 | 互动 | 产出 |
| --- | --- | --- |
| 1 开场 | 首页：竖排题名「竹简观兵」+ 副题「山东博物馆 · 银雀山汉墓竹简《孙子兵法》」+ 展卷/图鉴/声 按钮 | 氛围定调：夜青底 + 暖金主光 |
| 2 展卷 | 3D 卷轴静置可拖拽 360° 旋转；点「展卷」→ 编绳松开、卷体平铺展开（~2.5s，点按可加速），十三束自右向左落定，篇签浮起 | 高光时刻①：展卷 |
| 3 读篇 | 点篇签/束 → 该束前移放大，3 枚简立起；左右滑/箭头切枚；金句关键句描金；知识附片从侧滑出（可关闭） | 高光时刻②：金句 + 附片 |
| 4 手记 | 读完一篇可生成：选金句（默认为该篇金句）→ 仿古册页 900×1200 → 存相册/发笔记 | 高光时刻③：金句手记 |
| 5 收集 | 每读完一篇点亮图鉴；13 篇全亮解锁「全卷」页：银雀山之谜 + 全卷重览 | 收集闭环 |

- 失败态：无（纯展示不设失败）；教学浮层：首展「拖拽旋转 · 点展卷」，首读「左右滑看简」，之后不再出现
- 返回结构：read → browse → stage；图鉴可随时回 home
- 自驾模式：`?demo=1` 自动展卷 → 依次读 1-13 篇 → 生成手记（供无头冒烟 + 截图）

## 4. 技术方案

- `three.min.js`（复用 wenwu vendor，603KB）+ 自写轻 engine；不用 GLTFLoader、无外部模型
- 场景：PerspectiveCamera + PointLight（暖金）+ AmbientLight（冷青弱）+ 展台（程序化木纹 CanvasTexture）+ 微尘 Points（数百点缓慢漂移）
- 模型：卷 = 横置 Cylinder + 端盖；束 = 带纹理 Box/Plane + 卷边（局部 Cylinder）；简 = ThinBox + CanvasTexture
- 相机：手写轨道（yaw/pitch/zoom + 阻尼 + 范围钳制），读篇时目标点 lerp 锁定；双指缩放
- 拾取：raycast 篇签；pointer events 统一触摸/鼠标
- 文字纹理：OffscreenCanvas（DPR=2）竖排逐字绘制，从右至左排列，每枚简一组
- 音效：WebAudio 程序化——展卷竹节轻响、选篇「嗒」、翻简「簌」、环境低频风声；静音开关；无外部资源
- 存档：localStorage `zhujian-done[]`（篇次）；无网络
- 包体预算：<800KB（three 603KB + 业务 JS ~100KB + HTML/CSS/字体栈系统）

## 6. 验收标准（无头冒烟断言）

- 容器合规：无内联脚本/行内事件；资源全部在 zip 内；无被禁 API
- home 渲染，展卷按钮可点；`?demo=1` 自驾可推进至全部十三篇
- 展卷后 13 个篇签齐全；读篇后 3 枚简出现、简纹理 canvas 非空、附片内容非空
- 数据完整性：13 篇 金句/点睛/附片 均非空断言
- 图鉴：读一篇 `done+1`；13 篇全亮解锁「全卷」
- 手记：canvas 900×1200，像素非空；`window.xhs?.miniTool` 判空降级为「截图保存」提示
- zip：`dist/zhujian.zip` 独立解压 + http 源加载冒烟（沿用系列现有脚本模式）

# 山海经·御空（纵版射击）设计文档

- 日期：2026-08-31
- 系列：「非遗手作坊」#16
- 形式：纵版卷轴射击（雷电类改编）
- 状态：设计稿 → 原型

---

## 0. 产品定义

| 项 | 结论 |
| --- | --- |
| 核心玩法 | 雷电类：纵版卷轴，骑应龙在云海里飞，打扑下来的山海妖兽 |
| 改编逻辑 | 「往上打落下来的敌人」= 妖兽自天扑来；火力升级 = 法宝；炸弹 = 雷符清屏 |
| 文化锚 | 《山海经》妖兽图鉴（毕方/穷奇/蛊雕/混沌/相柳），每只附原文+释义 |
| 差异 | 博物馆系列里唯一的「神话向」；妖兽图鉴自带收集点 |

## 1. 核心循环

```
起飞 → 云海飞行（自动卷轴）→ 妖兽扑来 → 射击/法宝 → 过关/Boss → 御兽图鉴 → 分享
```

- 玩家应龙在屏幕下半部自由移动（拖动），**自动开火**（降低操作门槛，手机友好）
- 妖兽自上方扑下，被击落掉「灵石」（分数）与「法宝」（升级）
- 应龙被撞到掉「鳞」（3 鳞 = 3 命），鳞尽则坠

## 2. 妖兽（敌人，取自《山海经》）

| 妖兽 | 出处 | 行为 | 血量 |
| --- | --- | --- | --- |
| 毕方 | 西山经「有鸟焉，其状如鹤，一足」 | 火鸟，俯冲投火 | 低，快 |
| 蛊雕 | 南山经「其状如雕而有角」 | 成群俯冲 | 低，成群 |
| 穷奇 | 海内北经「状如虎，有翼」 | 高速横冲 | 中，快 |
| 混沌 | 西山经「浑敦无面目」 | 肉盾慢压 | 高，慢 |
| 相柳 | 海外北经「九首蛇身」 | **Boss**，九首轮番吐息 | 极高 |

## 3. 法宝（火力升级 + 道具）

| 法宝 | 效果 |
| --- | --- |
| 飞剑 | 基础火力，拾取升级：单剑→双剑→三剑散射 |
| 雷符 | 炸弹，清屏（限次，初始 2 张） |
| 八卦镜 | 护盾，挡一次撞击 |
| 灵石 | 分数/货币，计分与图鉴解锁 |

## 4. 关卡（原型 3 关）

| 关 | 名 | 内容 |
| --- | --- | --- |
| 1 | 南山经 | 毕方+蛊雕，教学 |
| 2 | 西山经 | +穷奇+混沌 |
| 3 | 海外北经 | 相柳 Boss 战 |

## 5. 御兽图鉴（收集）

- 每种妖兽首次击落解锁图鉴，附《山海经》原文 + 白话释义
- 集齐进度 = 重玩动机

## 6. 视觉与音效

- 背景：程序化云海卷轴（云层分层视差滚动）+ 远山
- 妖兽/应龙：wan2.7-image-pro 生成 + rembg 抠图（延续节气塔防工作流）
- 音效：程序化（射击/爆炸/拾取/坠毁），延续 WebAudio 工作流

## 7. 技术

- 纵版卷轴引擎：实体池（玩家/敌/弹/道具/粒子），碰撞 AABB，卷轴视差
- 复用节气塔防的无头仿真验证：每关贪心策略可解断言
- 包体目标 <1MB（素材抠图压缩）

# 月下灯会 · 设计文档

> 非遗手作坊系列第 18 作。自由创作型：用户自主设计灯纹，产出独一无二的彩灯，放入月下灯会。
> 创建日期：2026-09-13

## 1. 选题依据

- **回归月亮**：中秋的核心意象始终是月。本作以月为焦点与背景，灯会作为承载色彩与视觉效应的载体，二者不可偏废。
- **灯会传统**：中秋向来有灯会（赏月、观灯、放灯），是节令的核心活动之一。灯提供色彩与光，弥补月本身色彩变化有限的不足。
- **强视觉效应**：漆扇的好看源于染料在水中扩散产生强烈色彩流变。本作对应的是**灯光透过彩绘灯纹产生的透光效应**，以及**灯会群灯齐明在月下的视觉冲击**。
- **强分享属性**：每盏灯纹样独一无二，成品晒图传播力强，符合系列「可分享」原则。

## 2. 文化准确性（调研结论）

> 依据 `docs/research/yuedeng-lantern-customs.md`（529 行，10 节，81 条表格证据，21 处标注需核）。

### 2.1 中秋灯的功能 —— 本作的叙事根基

**中秋灯不是装饰，它是有功能的。** 文献给出的核心答案：

- **「燃灯助月色」「实与明月争辉」** —— 灯不是主角，月才是。灯存在的意义是与天上明月争辉。这直接印证 §1「回归月亮」的选题直觉。
- **「盖取光明之意」**（民国《中华全国风俗志·广东·广州岁时纪》）
- **灯／丁谐音 → 人丁兴旺**（潮汕方言「灯」与「丁」同音；娘家送灯给新嫁女求添丁）
- **团圆** —— 灯下聚饮，家人咸集

### 2.2 三个必须分清的节日（文化准确性红线）

| 习俗 | 真实归属 | 证据 |
| --- | --- | --- |
| **灯会**（公共大型灯展） | **元宵节** | 秦淮灯会 = 国家级非遗 Ⅹ-50，「主要集中在每年春节至元宵节期间举行」 |
| **放河灯** | **今俗属中元节**（但源头确在北宋中秋） | 周密《武林旧事》卷三·中秋原文可证；学术论文考证「放水灯始见于北宋，乃系在中秋节夜间举行的祈福、禳灾之行为」，南宋迁至中元 |
| **天灯／孔明灯** | **元宵节** | 张岱《夜航船》「正月十五日是天官生日，放天灯」；平溪天灯为元宵 |

**中秋的灯火是家户级的「满城灯火」**，不是元宵式公共灯会：每家自己挂自己的灯，入夜后满城灯火如明星罗列。**没有人「布置灯会」。**

### 2.3 纠错（原文有误）

原 §2「中秋灯会盛于唐宋」**有误，已改**：中秋节本身唐宋才形成（唐说／宋说有学术争论，萧放持宋代说），北宋太宗官方定八月十五为中秋节，明清才成为仅次于春节的第二大节。中秋灯火盛景的详载集中在**清代广州**（树中秋），不是「唐宋灯会」。

### 2.4 「月下灯会」名称可保留

依据：民国《中华全国风俗志》「即小孩亦有**提灯之会**」；1925 年广州提灯大会 5 万人参加；1956 年广州文化公园中秋灯会首办（1961 年近千盏、观众 100 万人次）；新马华人中秋提灯游行至今盛行，是「除了吃月饼之外最重要的活动」。知识卡需诚实划界：家户级满城灯火是古俗，公共大型中秋灯会是 1956 年起的现代事。

### 2.5 灯笼工艺与纹样

- **灯笼**：竹篾为骨、纸或绢为面、彩绘纹样、内置蜡烛。灯彩（仙居花灯、硖石灯彩、泉州花灯、东莞千角灯、湟源排灯）= 国家级非遗 Ⅶ-50。
- **中秋灯笼常见纹样**：月、桂、兔、云、花鸟。民谣「八月十五玉兔灯」（需核）。
- **月**：中秋核心意象，月满象征团圆。中秋节 = 国家级非遗第一批（2006），编号 Ⅹ-5。

### 2.6 核心魅力

灯纹由用户设计，独一无二；灯光透过纹样产生透光效应；**灯最终要高挂起来与明月争辉** —— 这是叙事的归宿，也是 CG 结局的内容。

## 3. 核心机制：做一盏灯（四道工序）

用户全程主导创作。月亮是背景与焦点，灯的归宿是**高挂起来与明月争辉**（§2.1）。

### 创作控制点

| 维度 | 用户控制 | 真实工艺对应 |
| --- | --- | --- |
| **扎骨** | 选灯形（圆灯、方灯、六角灯、莲花灯） | 竹篾骨架造型 |
| **裱糊** | 选灯面纸色（月白／桂金／朱砂／青金／黛蓝） | 纸绢裱糊灯面 |
| **画纹** | 选传统纹样（月／桂／兔／云／花鸟）落到灯面 | 彩绘灯面 |
| **染彩** | 在灯面拖动染色，彩漆扩散交织 | 灯面染色（保留，透光效果已验证） |
| **放灯** | 选放灯方式（高挂／手提／砌成字） | 放灯入夜 |

### 交互流程

1. **扎骨**：选竹篾骨架形状（圆灯／方灯／六角灯／莲花灯）
2. **裱糊**：选灯面纸色
3. **彩绘**（核心创作循环，可反复）：
   - **画纹**：选传统纹样（月／桂／兔／云／花鸟），纹样落到灯面，随灯体转动绕过去、点亮时一起透光
   - **染彩**：拖动染色，彩漆在灯面扩散交织
4. **点烛**：点亮灯笼，灯光透过纹样产生透光效应
5. **放灯**：选放灯方式，进入 CG 结局（§10）

## 4. 视觉特效（关键）

漆扇的好看源于染料扩散的强色彩流变。本作对应的强视觉效应是：

### 4.1 透光效应（核心特效）

灯点亮后，灯光透过彩绘纹样产生**透光效应**：纹样在光中显现，色彩在光中流变。这是本作的核心视觉效应，类比漆扇的染料扩散。

- 实现：灯点亮后，纹样的色彩在光中增强、流动、交织，产生透光效果。
- 可用 WebGL 流体或着色器实现光透过纹样的流变效果。

### 4.2 群灯齐明（灯会盛景）

灯会中群灯齐明，月下群灯构成视觉盛景。这是本作的第二视觉效应。

- 实现：用户的灯与其他灯共同构成灯会，群灯齐明在月下，视觉冲击力强。
- 月是背景与焦点，灯会是前景，二者共同构成中秋盛景。

### 4.3 月相（中秋核心）

月亮是中秋核心意象，必须有月相。本作月相与月宴一致（满月无云／满月薄云／明月半云／月出云中／薄云遮月），可复用月宴的月相渲染。

## 5. 视觉规格

## 9. 已决项（原型验证后锁定）

### 9.1 透光效应实现 — 已锁定（原型已验证）

WebGL 三层叠加：

1. **流体层**：复用漆扇 stable-fluids GPU 求解器（advection / divergence / Jacobi 压力 / gradient-subtract / vorticity confinement），驱动彩漆在灯面扩散交织。
2. **泛光层**：四分之一分辨率 bright-pass + 两次 ping-pong 高斯模糊。
3. **显示层**：着色器把颜料当作蜡烛光场上的滤光片——厚颜料吸收并透出深饱和色，薄颜料让暖白光透过。

灯形切换为四个 SDF 权重混合（形变而非跳变）。画布 `alpha:true`，灯形外全透明，CSS 月与星透出。

验证指标（点亮 vs 未点亮）：luma 84.23 → 138.53（+64%），饱和度 ×4.5，纯白 10.5% → 0.03%，光晕溢出 ×2.50。

### 9.2 灯会盛景构成 — 已锁定

- **数量与层次**：三层景深，共 26 盏背景灯 + 用户灯。远景 14 盏（小，沿屋檐）、中景 8 盏（中）、近景 4 盏（大）。
- **排列**：全部取自固定表（零随机）。远景沿天际线屋檐悬挂，中景挂于枝架，近景沿屋檐高挂。**不作水面浮灯** —— 见 §2.2，放河灯今俗属中元悼亡，且本系列已有《一盏河灯》（中元节），中秋场景出现水面浮灯会造成文化不一致与系列内自相矛盾。
- **光强度**：暖光 + 大气透视——越远越暗越冷，越近越亮越暖。每盏带柔和光晕。
- **联动**：用户灯点亮时，背景灯随之齐明（`is-lit` 状态驱动）。

### 9.3 月相与灯会的关系 — 已锁定

月相影响夜空环境光，进而改变灯会对比度：

| 月相 | 夜空环境光 | 灯光增益 | 视觉效果 |
| --- | --- | --- | --- |
| P1 满月无云 | 最亮 | ×1.00 | 月主导，灯柔和 |
| P2 满月薄云 | 次亮 | ×1.08 | 月灯均衡 |
| P3 明月半云 | 中 | ×1.16 | 灯渐显 |
| P4 月出云中 | 次暗 | ×1.26 | 灯突出 |
| P5 薄云遮月 | 最暗 | ×1.35 | 灯主导，最戏剧 |

物理依据：月越暗，灯的相对对比越强。用户可在不同月相下看到自己的灯呈现不同气质。

## 10. CG 结局：树中秋（本作最重要的部分）

> **这是本作最重要的部分。** 前面所有工序都是为了让这一刻成立。用户明确要求「展示很重要」，结局必须是 **CG 级叙事序列**，不是静态展示。

### 10.1 为什么必须是 CG 级而非静态展示

系列既有结局（月宴 `#view-ending` 七步揭示）本质是**静态场景 + 分步淡入**：元素早已摆好，JS 逐个加 class，CSS 做 opacity 过渡。没有运动、没有镜头、没有叙事弧线。**明确不以它为模板。**

| 维度 | 静态展示（不做） | CG 级（要做） |
| --- | --- | --- |
| 画面 | 带边框的固定构图 | **全画幅**，无面板遮挡 |
| 运动 | 元素淡入，位置不变 | **镜头推拉摇移**，元素真的在动 |
| 深度 | 单层 | **视差多层**，前后景不同速 |
| 氛围 | 静态元素 | **粒子系统**（浮光／流萤／火星），持续飘动 |
| 驱动 | CSS class + opacity 过渡 | **rAF 连续插值**，真实缓动 |
| 结构 | 分步揭示 | **叙事弧线**：起 → 承 → 转 → 合 |

### 10.2 叙事弧线（四拍）

依据 §2.1「燃灯助月色」「实与明月争辉」与 §3 放灯「高挂（树中秋）」。

| 拍 | 内容 | 镜头 | 时长 |
| --- | --- | --- | --- |
| **起 · 点烛** | 你画的那盏灯亮起，烛火点燃，纹样开始透光 | 特写，灯占满画面，四周压暗 | ~2.5s |
| **承 · 系竿高树** | 灯被举起，系上竹竿，挂到檐／树高处 | 镜头随灯上升（translate + scale） | ~3s |
| **转 · 满城灯火** | 家家灯火次第亮起，「满城灯火，如明星罗列」 | 镜头拉升拉远，视差层滚动，粒子飘动 | ~4s |
| **合 · 与月争辉** | 满城灯与月同框，灯光与月色交映 | 镜头定格，光达峰值 | ~3s |

总时长约 **12.5s**。第四拍内容「与月争辉」是史料原话（§2.1），不是编的。

### 10.3 技术要求

- **新建 `#view-finale` 全画幅视图**，不带任何面板边框或 chrome
- **主角是用户实际画的那盏灯**：从 WebGL 画布截图作为主角，**不是另画一个**
- **DOM/CSS 分层做场景构图** + `transform` 做镜头运动
- **独立 canvas 层做粒子系统**（浮光／流萤／火星），持续飘动
- **rAF 驱动时间轴**，每拍插值镜头与光，真实缓动
- **视差多层**：前景（屋檐／树）、中景（屋舍）、远景（夜空／月），不同速移动
- **零随机**：粒子位置与时序全部来自固定表或确定性函数
- **可跳过**：用户可点击跳过，但**不默认跳过**

### 10.4 三种放灯方式的结局差异

| 放灯方式 | 结局场景 |
| --- | --- |
| **高挂**（主结局） | 灯系竹竿高树 → 满城灯火 → 与月争辉（§10.2 完整四拍） |
| **手提** | 提灯沿街踏歌：镜头横向跟随，街景视差滚动，儿童提灯同行 |
| **砌成字** | 多盏灯砌成字形高揭：镜头拉升，字形灯阵次第亮起 |

三种**共用「与月争辉」的收束拍**，保证月始终是归宿（§2.1）。

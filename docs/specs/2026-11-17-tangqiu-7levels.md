# 糖球转转 v2 · 7 关闯关版设计

> 目标：把「一局 180 秒」升级成「7 关顺序闯关」，同时把武器、怪物、角色三条线做厚。
> 前作见 `docs/specs/2026-11-17-tangqiu-design.md`，美术规范见 `docs/specs/2026-11-17-tangqiu-art-pack.md`。

## 1. 核心循环变化

| | v1 | v2 |
|---|---|---|
| 结构 | 单局 180 秒 | 7 关顺序解锁，每关 90 秒（第 7 关 120 秒） |
| 成长 | 单局内升级 | **跨关继承**等级、武器、属性，一局打通 7 关约 12 分钟 |
| 失败 | 结算重开 | 结算重开（从第 1 关），已解锁关卡与皮肤永久保留 |
| 通关 | — | 解锁下一关 + 对应角色皮肤 |
| 关底 | 1 个 BOSS | 每关一个 BOSS，血条常驻顶部 |

**跨关继承规则**：等级、经验、武器与等级、属性加成、金币（无）全部带入下一关；**心心不重置，但每过一关回 2 点**（上限 8）。死亡即整轮结束。

| 4 | 巧克力矿洞 | 越挖越黑 | 90s | 可可棕 | 巧克力球、饼干兵、布丁 | 巧克力巨人 |
| 5 | 汽水河 | 别翻船 | 90s | 汽水蓝 | 瓶盖、泡泡糖、棉花蝠 | 汽水罐王 |
| 6 | 蛋糕城堡 | 守卫全醒了 | 90s | 草莓粉 | 蛋糕卫兵、草莓炮、饼干兵 | 三层蛋糕王 |
| 7 | 星空糖罐 | 最后一颗糖 | 120s | 深夜蓝 | 星星糖 ×2、草莓炮、泡泡糖、蛋糕卫兵 | 星空糖王 |

七只 BOSS 全部有专属立绘（内置王冠），不再走「放大杂兵 + 代码补冠」的降级路线。
怪池支持重复项加权：写两次 = 出现概率翻倍（第 7 关星星糖写两次，占 40%）。

**难度曲线**：敌人血量 `hp × (1 + (关卡-1) × 0.34 + 本关时间/150)`；刷怪间隔基准 `0.62 - 关卡×0.03`，并随本关时间收紧。BOSS 在本关结束前 20 秒登场。

## 6. 存档

`localStorage['tq2']`：

```json
{ "unlocked": 3, "skins": ["hero","mint","cocoa"], "best": { "level": 3, "kills": 512, "time": 245.6 } }
```

- `unlocked`：已解锁到第几关（1–7），首次进入为 1
- `skins`：已解锁角色 id 数组
- `best`：单轮最好成绩（到第几关、总击杀、总时长）
- 兼容旧键 `tq_best`：读到就折算成 `best.kills`，不迁移进度（老版本是单局制，没有关卡概念）

## 7. UI 变化

1. **标题页**：logo 下方加「选角色」横排卡片（4 张，未解锁显示锁与条件），点卡片切换；下方显示「已解锁到第 N 关」，按钮文案按进度变成「从第 1 关开始 / 继续第 N 关」。
2. **关卡标题卡**：进入每关时覆盖层显示「第 N 关 · 名称」+ 副标，1.6 秒后自动淡出，期间不刷怪。
3. **HUD**：右上角加关卡徽标「1/7」；BOSS 血条常驻。
4. **结算**：
   - 过关 → 「第 N 关通过」+ 本关数据 + 「进入第 N+1 关」按钮
   - 通关第 7 关 → 「七关全通」+ 总时长/总击杀 + 分享卡
   - 阵亡 → 「倒在 第 N 关」+ 本轮数据 + 「重头再来」

## 8. 体积预算

| 项 | v1 | v2 目标 |
|---|---|---|
| game.js | 62KB | **81KB**（实测） |
| 素材 | 2 张 133KB | **22 张 516KB**（实测） |
| zip 总计 | 17KB | **509KB**（实测，26 文件） |

素材用 8 位调色板 PNG（`quantize(128)`），杂兵/主角 200×200，BOSS 288×288，
单张 12–36KB。打包走 `scripts/build-tool.py tangqiu`，audit 0 warning。

> 体积取舍：一开始把上限设成 620KB 是自己出于首屏加载的顾虑，不是平台限制
> （同期 `hanfu.zip` 4.7MB、`wenwu.zip` 4.6MB 都过审了）。为了最终 BOSS 不长得像杂兵，
> 补了 3 张专属立绘，总量从 420KB 涨到 516KB，仍远低于平台上限。

## 9. 风险

| 风险 | 处理 |
|---|---|
| 7 关继承导致后关难度失控 | 敌人血量按关卡线性加成，武器上限 4 把，避免后期无脑碾 |
| 新怪物行为写得复杂，bug 多 | 每种只加一条特殊规则，其余走统一追击逻辑；冒烟测试逐种生成验证 |
| 素材 22 张风格漂移 | 全部沿用 art-pack 锚点逐字复用；每张生成后并排比对 |
| 关卡标题卡打断节奏 | 1.6 秒自动消失，且期间玩家可移动 |

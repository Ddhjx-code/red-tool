# 《小摊记》美术规范 v2（剪纸市集）

> 方法论来自 `game-art-prompt-pack`（风格锚点逐字复用 / 纯色底 / 只出单方向 / 效果不画进图），
> 视觉参考来自 `awesome-kimi-k3-game/effects/style-papercut`（CC0）与 `style-ink-wash`。
> 美术**全部程序化绘制**（Canvas 2D），不引入位图，体积代价接近零，且能实时换时段。

## 1. 风格一句话

**宋人市井的纸雕剪纸**：单色纸片分层叠压，靠**剪影轮廓 + 层间投影 + 纸纤维噪点**出体积，
不靠渐变与描边。整体是"一张张纸叠出来的街"，不是"画出来的插画"。

## 2. 风格锚点（改动必须同步全部绘制函数）

- 轮廓：外缘干净利落，只用直线与二次贝塞尔；**不做手抖抖动线**
- 体积：每层向右下偏移 2–4px 画一层 `rgba(42,36,32,0.10)` 投影，模拟纸片厚度
- 材质：每层叠加 800–1200 颗 1–2px 噪点（白 0.06–0.14 / 黑 0.04–0.08），只落在纸片内部（`source-atop`）
- 镂空：云纹、窗棂、瓦当用 `destination-out` 挖空，露出下一层颜色——**这是剪纸感的关键**
- 禁止：外发光、柔和渐变、毛玻璃、描边高光、任何写实渐变体积

## 6. 客人（剪纸小人）

统一朝左（走向摊位），`scaleX` 由代码控制，不画两个方向。

| 型 | 剪影线索 | 颜色线索 | 行为 |
| --- | --- | --- | --- |
| 妇人 | 发髻 + 挎篮 | 青灰 | 只问贱货 |
| 书生 | 方巾 + 长衫直摆 + 持卷 | 赭 | 偏好扇、纸鸢 |
| 孩童 | 矮一截 + 总角双髻 | 朱 | 只问糖画、糖葫芦 |
| 老者 | 驼背 + 拐杖 | 黛 | 出价低但从不空手走 |
| 富户 | 圆肩 + 大袖 + 提灯 | 金 | 只问花灯，出价高 |

## 7. 动效（全部代码叠，不画进静态层）

- 灯笼：绕挂点 ±6° 正弦摆动，周期错开
- 幌子/旗：底边顶点按 sin 扰动
- 炊烟：3–5 颗粒子上浮 + 横向漂移 + 淡出
- 客人：走路时整体上下 1.5px + 左右微倾，脚步节奏 320ms
- 成交：3–5 枚方孔钱从摊位抛物线飞向左上，旋转
- 结算：印章从 1.6 倍缩放砸落 + 轻微旋转，纸面震一下

## 8. 性能约束

- 静态五层预渲染到离屏 canvas，每帧只 `drawImage` 平移，不重画路径
- 噪点只在预渲染时撒一次
- 动态层每帧元素上限：客人 4 + 粒子 24 + 钱 12
- 画布 DPR 上限 2；`resize` 重建层，节流 200ms
- 目标：中端机 60fps，低端机不低于 40fps

## 9. 验收自检

- [ ] 缩到 320px 宽仍能看出是"街市"，不依赖文字
- [ ] 四个时段换色后，同一构图可辨识

- [ ] 无外发光、无柔和渐变雾化（违反剪纸风格）

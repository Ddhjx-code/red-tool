## 〇、通用要求（3 张全部适用）

1. **画布 720×1280 竖版**（对齐系列；`guiyue` 场景图基准）。
2. **画风钉死到具体画种**：用 `工笔画 / 青绿山水 / 绢本设色 / Tang Dynasty`，
   **禁止裸 `国风` 或裸 `Chinese style`**（→ 通用感，见 §6.6）。
3. **色板 hex 必须写进提示词**（不得自行调色）：
   月白 `#EEF7F2` · 素衣 `#F2F0E6` · 银白 `#F1F0ED` · 青黛 `#1A3A5F` ·
   黛青 `#2A475F` · 石青 `#2E5D8C` · 缃绮 `#F8C471` · 朱红 `#ED5126`。
   取自 `zhongguo-traditional-colors`（⭐1,183）权威色表。
4. **单一暖锚点纪律**：整个冷青世界里**只允许一个暖色 = 缃绮桂花金**。
   暖色不得四处溢出（研究结论：single warm focal = premium）。
5. **提示词长度 50–200 字**，「使用具体的描述替代抽象概念」。

### 固定风格后缀（3 张必须逐字节相同，直接复制）

```
工笔画，绢本设色，青绿山水基调，月白#EEF7F2、石青#2E5D8C、缃绮#F8C471 色板，宣纸质感，留白构图
```

> ⚠️ 一致性杠杆最高的一项就是这个后缀。**三张之间不得有任何改动**（含标点与空格）。

### 禁用词（§6.6，三张全部适用）

| 类别 | 禁用 |
| --- | --- |
| 质量套话堆叠 | `8K` `ultra HD` `highly detailed` `masterpiece` `best quality` `trending on artstation` `award-winning`（最多留一个 `高清`） |
| 无指涉形容词 | `beautiful` `amazing` `stunning` `epic` `cinematic`（单独使用） |

## 一、`bridge` 银桥 — 测「体积光」与「桥随步而灭」的视觉可行性

| 项 | 内容 |
| --- | --- |
| 文件 | `scene_bridge.png` |
| 负向预设 | **`landscape`**（本场景无人物，可排除人物） |
| 文献依据 | 「化为大桥，其色如银」「寒色侵人」 |

**提示词**（复制即用）：

```
一道银白色石桥横跨夜空，桥体自画面下缘蜿蜒延伸至上方的巨大满月，桥面微微发光。
唐代中秋望夜，桥下云海翻涌，人间宫阙灯火在远处下方若隐若现。
全景，平视，广角。月光倾泻，体积光，光束穿透，雾气光线，冷色调光，低照度。
工笔画，绢本设色，青绿山水基调，月白#EEF7F2、石青#2E5D8C、缃绮#F8C471 色板，宣纸质感，留白构图。
```

**负向提示词**：

```
人物，文字，水印，建筑物变形，不自然颜色，过度饱和，text，watermark，oversaturated
```

**本张须规避的失败模式**（§6.5）：**不要让云横穿月轮**——「云层横穿山体」易触发建筑与云雾重画。
运动交给前景云海，月轮保持静止完整。

## 二、`gate` 广寒清虚之府 — 测「仰视崇高感」与「兵卫人物」

| 项 | 内容 |
| --- | --- |
| 文件 | `scene_gate.png` |
| 负向预设 | **`portrait`**（⚠️ 本场景有兵卫，**不得用 `landscape`**，否则人物被负向词抹除） |
| 文献依据 | 「榜曰广寒清虚之府」「守门兵卫甚严，白刃粲然，望之如凝雪」 |

**提示词**（复制即用）：

```
一座巍峨的月宫宫门矗立夜空，门楣悬匾额，门前两名兵卫持白刃肃立，白刃粲然望之如凝雪。
唐代月宫广寒清虚之府，夜空青黛深邃，宫门之上月轮高悬，月轮完整不被云层遮挡。
全景，仰视。月光倾泻，轮廓光，冷色调光，低照度，兵卫身形与宫门边缘清晰分离。
工笔画，绢本设色，青绿山水基调，月白#EEF7F2、石青#2E5D8C、缃绮#F8C471 色板，宣纸质感，留白构图。
```

**负向提示词**（`portrait` 预设 + 必带项）：

```
变形的手，多余手指，面部变形，不对称眼睛，extra fingers，deformed hands，
文字，水印，建筑物变形，不自然颜色，过度饱和，text，watermark，oversaturated
```

**镜头理由**：仰视「conveys grandeur」（`openakita` 原文），宫门须显崇高威严。
这是 §6.4 里 `gate` 指定仰视的依据。

**本张须规避的失败模式**（§6.5）：**不要让云横穿月轮**——首版试稿即因此被否（月轮被云层与屋檐双重遮挡）。
运动交给前景云海，月轮保持静止完整。

## 三、`court` 广庭素娥舞 — **本作最高风险，防糊成败在此**

| 项 | 内容 |
| --- | --- |
| 文件 | `scene_court.png` |
| 负向预设 | **`portrait`**（⚠️ 素娥为人物，**不得用 `landscape`**） |
| 文献依据 | 「素娥十余人，皓衣乘白鸾，往来笑舞于广陵大桂树之下」 |

**提示词**（复制即用）：

```
十余位素娥身着皓衣、乘白鸾，在一株巨大桂树下起舞，衣袖飘举。
唐代月宫广庭，广陵大桂树之下，夜空高远，庭前留白开阔。
远景，平视。月光倾泻，轮廓光，逆光，体积光，冷色调光，
素娥皓衣靠轮廓光与逆光从深色夜空底上清晰跳出。桂花为缃绮金。
工笔画，绢本设色，青绿山水基调，月白#EEF7F2、石青#2E5D8C、缃绮#F8C471 色板，宣纸质感，留白构图。
```

**负向提示词**（`portrait` 预设 + 必带项）：

```
变形的手，多余手指，面部变形，不对称眼睛，extra fingers，deformed hands，
文字，水印，建筑物变形，不自然颜色，过度饱和，text，watermark，oversaturated
```

**为什么这张是成败关键**（§6.5）：
白-on-暗若无 rim light 必糊成一片。**「素娥皓衣 + 轮廓光」是本作防糊第一杠杆**。
提示词里已显式写明「靠轮廓光与逆光从深色夜空底上清晰跳出」——若出来仍是糊的，
说明轮廓光权重不足，需加强该句或改用图生图链。

**本张须规避的失败模式**（§6.5）：
- **桂树不得整树摇动** → 只允许枝干摆动（「整棵柳树摇动」易生成脱落树叶）
- **白鸾须贴近锚点中心** → 不做长距离位移（「飞鸟落到树枝」易复制）

## 五、验收口径（我无视觉能力，需你眼验）

我无法判断画面好坏，只能给客观清单。请逐条过目：

| # | 检查项 | 判据 | 不合格的后果 |
| --- | --- | --- | --- |
| 1 | **素娥皓衣是否与暗底分离** | 白鸾/皓衣边缘清晰可辨，不与夜空融合 | 防糊失败 → §6.5 轮廓光需加强 |
| 2 | **银桥是否读作发光体** | 桥体有体积光感，非灰色平带 | → 体积光/光束穿透权重不足 |
| 3 | **宫门是否显崇高** | 仰视透视明显，门楣在上 | → 仰视未生效 |
| 4 | **色板是否守住** | 冷青主导 + 月白 + 缃绮桂花金 | → hex 注入失效，色板漂移 |
| 5 | **暖色是否只有一个锚点** | 只有桂花金是暖色，无其他暖色溢出 | → 违反 §6.1 纪律 |
| 6 | **云是否横穿月轮** | 月轮完整无云遮挡 | → 触发重画，需重出 |
| 7 | **是否一眼可读为中秋** | 满月 + 桂树 + 月宫可辨 | **bobing 首版被否的根因**，必须过 |
| 8 | **是否有 AI slop 感** | 无塑料光泽、无过度饱和、无套话堆叠痕迹 | → §6.6 禁用词需收紧 |

**第 7 条是硬门槛**：bobing 首版就是因「看不出和中秋的关系」被否。
若这 3 张过不了第 7 条，不得进阶段 2。

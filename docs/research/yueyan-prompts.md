> 用途：兑现 `docs/specs/2026-09-10-yueyan-rework-amendment.d/0d-bitmap-split.md`
> 0d-§4.1 的**权威素材清单（22 项）**。本文档给出每张素材的**生成期提示词**，
> 由 `tests/gen_yueyan_assets.py` 逐字读取执行。
> 出图平台：通义万相（`wan2.7-image-pro`，与系列同平台），契约见
> `docs/research/maas-image-api.md`。
> 提示词纪律继承自 `docs/research/yuegong-prompts.md`。

## 〇、通用要求（22 张全部适用）

1. **生成尺寸一律 `768*768`（星号，不是 `x`）**。网关总像素区间
   **[589,824, 16,777,216]** 为硬限制，超出即 **HTTP 400 InvalidParameter**
   （非静默回落）；下限 589,824 = 768² 且**含端点**（实测 `768*768` 通过、
   `512*512` 被拒）。清单 22 项的入库尺寸全部 < 768，故**全部 22 行都必须
   经本地降采样得到**，无一行可直接生成。
2. **强制三步管线**（0d-§4.4）：`生成 768*768` → `Pillow LANCZOS 降采样
   （非方形目标先中心裁切）` → `webp quality=80`。**降采样是强制步骤，不是
   可选回退。**
3. **画风钉死到具体画种**：`工笔线描` + `宋代笺纸小品画`。
   **禁止裸 `国风` 或裸 `Chinese style`**（→ 通用感、不一致）。
   这一画种同时完成**系列区隔**：`纸本小品`（暖、室内、纸质）对
   yuegong 的 `绢本设色 + 青绿山水`（冷蓝仙境），对 bobing 的 `墨黑底 + 金色高光`，
   对 guiyue 的 `高对比暗调`。
4. **色板 hex 必须写进提示词**（不得自行调色），**恰好七个 token，别无其他**：
   米纸 `#F7EFE2` · 赭石 `#B8733A` · 朱砂 `#C9483C` · 墨褐 `#3A2E26` ·
   月白 `#F2E4C4` · 桂花金 `#E8B84B` · 灯笼黄 `#F5C77E`。
5. **单一暖锚点纪律**：每张提示词只允许**一个**暖色锚点，暖色不得四处溢出。
6. **提示词正文 50–200 字**，「使用具体的描述替代抽象概念」。
7. **米纸纹理必须问出来**：§8.3 第 844 行明文「不用纯平色块」，故后缀内含
   `米纸纤维细噪点质感，不用纯平色块`。

### 固定风格后缀（22 张必须逐字节相同，直接复制）

```
工笔线描，平涂设色加单层内阴影，宋代笺纸小品画基调，室内灯下暖调，色板严格限定为米纸#F7EFE2、赭石#B8733A、墨褐#3A2E26、月白#F2E4C4、桂花金#E8B84B、灯笼黄#F5C77E，不得引入板外色，米纸纤维细噪点质感，不用纯平色块，不用渐变高光，不用塑料厚涂，不用粗黑卡通描边，高清。
```

> ⚠️ **一致性杠杆最高的一项就是这个后缀。22 张之间不得有任何改动（含标点与空格）。**
> `tests/gen_yueyan_assets.py` 在发任何请求之前**断言其逐字节相同**，
> 断言方式与 `tests/gen_yuegong_scenes.py:136-140` 同构（取每张提示词的
> **最后一行**构成集合，集合必须恰好只有该后缀一个元素，且与该常量
> **逐字节相等**），不一致即 `FATAL` 退出、一张都不发。

### 为什么朱砂 hex 不进后缀（唯一的有意例外）

后缀注入 **6 个** hex，`朱砂#C9483C` **不在其中**。理由：

| 事实 | 后果 |
| --- | --- |
| 0d-§4.3-b：朱砂**仅**出现在 A-03 / A-04 / A-05 / A-19，其余 **18 张不得含朱砂** | 若后缀（22 张共用）含朱砂 hex，等于给 18 张**不该有朱砂**的素材授权朱砂 |
| §8.2：朱砂占比 ≤ 5%（硬上限），实测最近色归属仅 0.67% | 后缀注入朱砂会把 0.67% 推高，直接威胁 V-21 |

故朱砂 hex **只写进 A-03 / A-04 / A-05 / A-19 四张的正文**。这不是漏注入：
「色板 hex 必须写进提示词」在 22/22 张上成立（后缀 6 个 hex 全员注入），
第 7 个 hex 在需要它的 4 张上注入。**这是把「七 token 闭板」与「朱砂稀有」
两条同时满足的唯一写法。**

### 禁用词（22 张全部适用）

| 类别 | 禁用 |
| --- | --- |
| 质量套话堆叠 | `8K` `ultra HD` `highly detailed` `masterpiece` `best quality` `trending on artstation` `award-winning`（**最多留一个 `高清`**，已在后缀内） |
| 无指涉形容词 | `beautiful` `amazing` `stunning` `epic` `cinematic`（单独使用） |
| 空泛文化词 | 裸 `国风` / 裸 `Chinese style` |
| 裸冷词 | `冷色调` / `蓝色调` / `银白色` / `dark` / `night` 单独使用（→ 与 yuegong 撞车，见下） |
| 渐变与厚涂 | `渐变高光` `塑料厚涂` `粗黑卡通描边`（违背 §8.3 第 845–846 行） |

### 禁用符号（11 项，0d-§4.3-d）→ 进 `negative_prompt`

```
玉兔，嫦娥，月宫，广寒宫，现代月饼礼盒，塑料包装，西式蛋糕，慕斯，奶油，
红色喜庆灯笼阵，春节
```

这 11 项**不可像素化测量**（画面里有没有「嫦娥」无法用色值判定），
故**提示词层排除是唯一防线**：全部进 `negative_prompt`，并在本文档逐张记录。
V-19 的素材半边由「画面内容 + 文件名 + 生成 prompt」三处核验（0d-V-I）。

**⚠️ A-10（灯笼）的负向词必须换用专版**：通用负向词含
`红色喜庆灯笼阵`，其中的「灯笼」概念会把 A-10 自己的主体一起抑制掉。
A-10 因此改用 `NEG_LANTERN`——**去掉「灯笼阵」整词**，改以
`红色，大红色，成排阵列，多盏，喜庆装饰` 表达同一条禁令。
这不是放宽禁令，是**把同一条禁令换成不伤主体的措辞**（详见 A-10 条目）。

### 冷色纪律（系列区隔，0d-§4.3-e）

本作必须是**暖的、室内的、纸与灯的**。通用负向词因此固定含
`冷色调，蓝色调，银白色，blue tone`——**冷蓝会与 yuegong 直接撞车**，
是同系列里最贵的失败模式。A-07（圆月）另在正文内再写一遍
「不偏冷蓝不偏银白」，因为月亮是最容易漂成冷白的主体。

## 二、22 张素材逐条提示词

> 每张的**生成尺寸一律 `768*768`**；**入库尺寸**与**降采样步**逐字取自
> 0d-§4.1；**上限 KiB** 为 0d-§5.3.2 的分档内部目标（T1 60 / T2 25 / T3 10），
> 外层另有 V-30 的 `≤ 160 KB` 兜底上界。

| 依据 | **§8.3 第 844 行**（既有锁定条款，0d-§1.1 的最强论点） |

**正文**（复制即用）：

```
一张米黄色手工米纸的近距离平铺纹理特写，纸面布满细小植物纤维与轻微凹凸，纤维走向随机无规律，明度在基准色上下百分之三内浮动，画面四边纹理连续相接可无缝拼接，无任何物件、无边框、无图案、无接缝线。
```

**本张的三条特殊性**：

1. **无主体**，故**不适用**「主体居中 + 留余量」的构图要求——它是一张满画布纹理。
2. **平铺无缝性**是硬要求（0d-§4.3-i）。生成期只能「要求」边缘纹理相接，
   **不能保证**；接缝的最终判定落在**唯一一次人工 contact sheet 目视**上
   （见 §四），不另建自动化平铺门禁。
3. **降采样不得破坏无缝性**：1.5:1 LANCZOS 是均匀重采样，不引入方向性条纹。

### 体积预估的换算依据

q80 实测每像素成本 **0.1622 B/px**（146 KiB ÷ 921,600 px，q80 @ 720×1280 实测）。
分档上限 = q80 换算值 × 余量系数：T1 `41.5 × 1.45 = 60.2 → 60 KiB`；
T2 `17.5 × 1.43 = 25.1 → 25 KiB`；T3 `2.6 × 3.8 = 9.9 → 10 KiB`。
余量系数覆盖两项使实际体积**高于**一阶预测的因素：**(a)** 网关返回
`mode=RGBA`，webp 需单独编码 alpha 层；**(b)** 降采样后小尺寸的**边缘密度
相对更高**。反向因素是 §8.3 的平色低熵美术，故余量不必更激进。

### 质量档纪律：**q80 双向锁定**

`quality=80` 恒定。**超档的素材不能用「降质量」修**——降到 q80 以下会触发
V-30 的质量档门禁。**合法补救只有两条**：**(1)** 降入库尺寸（但短边不得低于
128 px）；**(2)** 重新生成更低熵的构图。脚本对超档素材**只告警不自动降质**。

### 脚本自动做的（客观、可程序化）

| # | 检查项 | 判据 |

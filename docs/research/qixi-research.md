## 0. 给产品的结论速览

- 七夕节 **2006 年列入首批国家级非物质文化遗产名录**（国发〔2006〕18 号，第一批共 518 项），类别为**民俗**（传统节日）。
- 七夕本质是**「乞巧节」——女子向织女乞求巧艺**，爱情（牛郎织女）是后世叠加的主题。工具主打「乞巧/占卜」比主打「情人节」更贴非遗本意，也更差异化。
- 与工具玩法直接对应的真实习俗是**「丢针试巧」（投针卜巧）**：七夕午时把针投入水中，看针在水底的影子形状占巧拙。这是**有明确史料记载的占卜行为**，天然适合做成「投针 → 显影 → 占卜」的互动。
- 辅助习俗可作彩蛋/图鉴：穿针乞巧、蜘蛛应巧、巧果、拜织女、花瓜、磨喝乐。

## 1. 节日起源与牛郎织女

- 七夕源于**古人对自然星象的崇拜**（织女星/牵牛星的观测），后逐渐叠加祈福许愿、乞求巧艺、祈祷姻缘等习俗（ihchina 已核实此表述）。
- 牛郎织女传说：牵牛、织女作为星名最早见于《诗经·小雅·大东》（「跂彼织女」「睆彼牵牛」，此时尚无故事）；故事成形于汉代（《古诗十九首·迢迢牵牛星》已是完整相思叙事）；「鹊桥相会」的情节在六朝后定型。
- 七夕因此兼具**星宿崇拜 + 女红乞巧 + 爱情祈福**三层内涵。

## 2. 天文（用于知识卡与视觉）

- **织女星** = Vega（天琴座 α），北半球夜空最亮星之一；**牵牛星** = Altair（天鹰座 α）。
- 两星隔**银河（天河/银汉）**相望；与天津四（天鹅座 α）构成**夏季大三角**，七夕前后正是北半球观测最佳时节。
- 天鹅座横卧银河之中——「鹊桥」在星图上恰可对应天鹅座，是个可写进知识卡的浪漫细节。

## 3. 乞巧诸俗（工具玩法的素材库）

### 3.1 穿针乞巧（最早、最主流）
- 七夕夜女子**月下穿七孔针**，穿过者为「得巧」。
- 源流：汉已有之（见下《西京杂记》），六朝《荆楚岁时记》成系统记载，唐宋沿袭。
- 五色/七彩丝线称「巧线」「五色缕」。

### 3.2 丢针试巧 / 投针卜巧（工具核心，明清盛行）
- 七夕**午时**盛水一碗，把绣花针**轻轻投/平放于水面**（利用水的表面张力使针漂浮），观察**针在水底的投影形状**占巧拙：
  - 影如**云霞、花、鸟、兽**，或如**鞋、剪刀**等物形 → **「得巧」**（巧兆）
  - 影**粗如槌、细如丝、直如烛**（无成形） → **「未得巧」/拙**
- 这是「观察 + 想象 + 占卜」的行为，针影形状由水面张力、光线、针的沉浮随机决定——**与「随机显影 + 解读」的工具机制完全同构**。
- 出处：明·刘侗、于奕正《帝京景物略》（**需核**原文）；同类记载亦见于明清方志笔记。

### 3.3 蜘蛛应巧（唐）
- 七夕捉小蜘蛛（古称「喜子」）置于盒中，次日晨**看蛛网疏密**：网**圆整/密**为「得多巧」，**稀**为「得少巧」。
- 出处：五代·王仁裕《开元天宝遗事》记唐宫事（**需核**原文）；更早的「喜子网于瓜上以为符应」见《荆楚岁时记》。

### 3.4 巧果（食俗）
- 用油、面、糖、蜜炸/烙成各种花样的点心，称**「巧果」**（又叫「乞巧果子」），宋已盛行。
- 出处：宋·孟元老《东京梦华录》记汴京七夕「以油面糖蜜造为笑靨儿，谓之『果食』」（**需核**原文）。

### 3.5 拜织女 / 供瓜 / 乞巧楼
- 七夕夜女子**陈瓜果于庭中**，设香案拜织女，对月穿针乞巧。
- 宋时富贵人家于庭中**结彩楼，称「乞巧楼」**（《东京梦华录》，**需核**）。
- 还有「花瓜」（把瓜雕成花样）、「磨喝乐」（小塑土偶，宋时七夕应节玩偶）等。

## 5. 诗词文案素材（可直接用于卡片/文案）

- 《古诗十九首·迢迢牵牛星》（汉）：「迢迢牵牛星，皎皎河汉女。纤纤擢素手，札札弄机杼。终日不成章，泣涕零如雨。河汉清且浅，相去复几许。盈盈一水间，脉脉不得语。」
- 林杰《乞巧》（唐）：「七夕今宵看碧霄，牵牛织女渡河桥。**家家乞巧望秋月，穿尽红丝几万条。**」——最贴「乞巧」主题，可作首页点睛。
- 杜牧《秋夕》（唐）：「银烛秋光冷画屏，轻罗小扇扑流萤。天阶夜色凉如水，**卧看牵牛织女星**。」——夜景氛围佳句。
- 秦观《鹊桥仙》（宋）：「纤云弄巧，飞星传恨，银汉迢迢暗度。金风玉露一相逢，便胜却人间无数。柔情似水，佳期如梦，忍顾鹊桥归路。**两情若是久长时，又岂在朝朝暮暮。**」
- 白居易《长恨歌》（唐）：「**七月七日长生殿**，夜半无人私语时。在天愿作比翼鸟，在地愿为连理枝。」

## 6. 对《乞巧占卜局》设计的落地

### 6.1 显影系统（针影 → 占卜结果）
- 史料给的影形可直接做**图鉴/结果集**：云霞、花、鸟、兽、鞋、剪刀（得巧类）＋ 槌、丝、烛（未得巧类）。
- 为「结果多样性」可把影形扩展成 12 种（见 spec），但**每一种都应能回溯到「针影如某物」的占法逻辑**，避免凭空捏造。
- 「未得巧」措辞要温和（史料本意是占巧拙、讨彩头，不是诅咒）——给鼓励性解读。

### 6.2 占卜维度（组合出多样性）
- **影形**（显出来的形状）× **巧运面向**（针工/文采/姻缘/家宅/财市）× **品级**（上上巧→未得巧）。
- 「心诚值」（定心环节的操作表现）影响品级分布——把玩法表现与占卜结果挂钩，增强「是我占出来的」参与感。

### 6.3 知识卡素材
- 七夕 2006 首批国家级非遗（民俗类）。
- 丢针试巧的出处与玩法（《帝京景物略》）。
- 织女星/牵牛星/夏季大三角/鹊桥=天鹅座的天文浪漫。
- 「家家乞巧望秋月，穿尽红丝几万条」。

## 7. 视觉素材方向（程序化，无外部图）

- **夜色基调**：黛青/藏青夜空（#2e3d52 系），一轮明月，薄云，星点（可点出织女星、牵牛星、银河）。
- **水盆**：青花或素瓷圆盆，水面有月光高光与涟漪；针为细长银亮一线，浮于水面。
- **针影**：盆底投影用半透明墨色剪影，形状即占卜结果（云/花/鸟/兽/鞋/剪等矢量剪影）。
- **点缀元素**：喜鹊（鹊桥）、蛛网（蜘蛛应巧彩蛋）、巧果、七孔针与五色线。
- **色彩**：沿用系列传统色——朱红 #C3272B、黛青 #425066、藤黄 #FFB61E、月白 #D6ECF0、宣纸 #F5F0E6；夜色场景以黛青+月白为主，朱红/藤黄做点睛。

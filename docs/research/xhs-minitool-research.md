## 2. 案例深拆（数据+评论证据）

### 2.1 拼豆图纸生成器（未来设计师KiK）——首个破 1 万使用（破万原因已验证）
- 官方背书笔记 265 赞；作者被翻牌后评论：「哇好感动被薯翻牌子啦🥹后续会继续迭代」
- **破万原因拆解（实访验证，非推测）**：
  1. **拼豆圈在小红书是万赞级流量池**：搜「拼豆」头部笔记——「少女木偶｜原神拼豆图纸」1.1万赞、「就这个辛芙萌！」1.2万赞、「图片转图纸推荐用啥？」3126赞。拼豆图纸本身就是高赞内容品类
  2. **图纸是这个圈子的内容硬通货**：用户发图纸笔记赚赞 → 生成器（任意图→图纸）= 内容产能放大器，用它能批量产出圈子里最吃香的内容
  3. **官方下场助推**：手工薯《图纸自由时代来临！小红书官方工具正式上线》5604赞 + 小红书创作学院同步发笔记——平台把拼豆工具当标杆运营
  4. **工具生态已卷起来**：智绘云免费版 4239赞、灶门花子「游戏内40色生成」4011赞——首个破万者吃到的是品类红利+首发认证，不是质量优势
- **质量真相**（高赞差评）：「这个效果和很多软件比起来也差很多了，基于传统的图像降采样，完全没有拼豆特色，建议看看千岛的效果」（19赞）、「并不是很好用，期待好好打磨再发出来」（8赞）
- **用户晒单证据**：28 粉素人「小红qwq」发笔记《发现一个超好用的拼豆图纸生成器网站》（231赞），正文就是晒生成结果「弄了个雾子的图纸玩玩」，评论区「感谢楼主」+互相分享其他生成器——**生成器类的晒单=晒产物（图纸），且用户会自发安利工具**
- **结论**：破万 = 万赞级垂直圈 × 产物即内容 × 官方助推；质量平庸照样破万，但评论区立刻有竞品抢流量——头部笔记评论区是战场

### 2.2 猫头大王（133 粉，2577 获赞藏）——高频迭代街机型
- 主页轨迹：「流水线练手①是男人下100层 → ②简化天天酷跑 → 熊猫 → 猫猫酷跑(320赞) → 滑雪(158赞) → 钻矿大王(645赞)」，账号简介只有四个字「善假于物」
- **钻矿大王（645赞/220藏/78评，评论率极高）的笔记正文就是游戏存档**：「这是我的当前改装：钻头T1·Lv.1、履带T1…最深纪录 35 格。欢迎体验小工具钻矿大王，期待大家分享更多藏宝图和好看的配色！」
- 评论生态（玩家教玩家+作者快修）：
  - 「挖了一万多米还是没找到」（深度游玩炫耀）
  - 「好累，二十级以后为啥没有钻头了」（进度抱怨=留存证据）
  - 「改装和退出在一块点不到改装怎么办？」→ 作者：「**已经修复了在审核，明天就好了**」
  - 「挖完矿回不去了」→ 玩家互答：「右上角有个返程按钮，长按一下」
  - 作者在评论区发兑换码：「钻矿大王666：金币×6666…」
- **点墨系列**（挑战模式，11+ 关）：作者自发「**开发者本人被第七关难住了 求高手**」（27赞）；玩家：「抓住野生作者，快去更新下一篇！！！11关太难了，什么时候出教程」「这个好玩 第七关好难」→ 作者引导：「玩家可以看看往期笔记，有大佬出了完美通关教程～」——**难度→求助→攻略→二次内容**闭环
- 发现摩擦：「怎么能在xhs上直接打开的？」→「小工具。电脑打开创作者中心就有」——**大量用户不知道组件在哪**

- 参赛自我介绍原文：「方块谷 **1w➕人玩过**的纪念碑谷风格的解压轻推理游戏，**上线乞巧节特殊篇章挑战**。快来试试你能否完美通关，拿下**限定特殊成就**吧！」

### 2.4 三星堆修复局（南野造物，30赞/22藏）——我们文物修复局的直接竞品
- 图文笔记，标题「把三星堆做成修复小游戏，真的上头」；数据平平但藏/赞比 0.73（工具型内容特征：收藏>点赞）
- 评论：「方便问问用的哪种ai吗，我最近也在做文博类的设计」→「用的 GPT」——**同行密度高，文博赛道已有人占位但未出现爆款**

### 2.5 玩家晒单生态验证（「可炫耀记录」假设的实证）
第一轮报告称「可炫耀的记录」驱动传播，但只引用了作者自己的文案。本轮搜索验证：**玩家真的会发笔记晒小工具成果**，集中在方块谷：
- 「一只小him🎐｜方块谷 1~10关 完美通关攻略」171赞——玩家自发攻略笔记
- 「一只小him🎐｜方块谷乞巧篇 完美通关攻略」41赞——限定篇章也有攻略
- 「方块谷 初谷篇通关！」「星门篇通关！」「全10关通关！」「乞巧挑战通关！」——至少 6 个不同玩家（小嘻柚/越越控/EGGYMA/清和/一二/我去不早说）发了「XX篇通关」晒单笔记（2-6 赞，量多赞少但真实存在）
- 作者小九的AI实验室（《小红书首游上线》924赞）在大赛评论区回复玩家：「玩家可以看看往期笔记，有大佬出了完美通关教程～」——**作者主动把玩家攻略纳入运营闭环**
- 游戏类晒单的另外两种形态：难度吐槽帖（「小红书也能玩小游戏！绝对色感也太难了吧！」113赞）、挑战钩子帖（「小红书第1款游戏来啦：你试你也过不了第二关」154赞、「徒手画个圆，你能到几分」332赞）
- 对照组：钻矿大王没有玩家晒单笔记，炫耀只发生在作者笔记评论区（「挖了一万多米还是没找到」）——**差别在于方块谷有「篇章/完美通关」这种值得单独发笔记的成就结构**

**对战棋的启示**：晒单需要「可命名的成就单元」。我们的五篇兵法+三星评价天然适配「虚实篇 3回合斩旗」「谋攻篇 0击杀通关」这种晒单标题——战报卡要为此设计（篇名+战绩要一眼可读）。

### 2.6 低互动样本（失败特征）
- 大赛评论串 122 条参赛回复中，约半数只有「赞」级互动、无回复；其共同点：一句话广告（「XX 来了来了～」「交作业」）、无玩法描述、无钩子
- 对比高互动回复都带：玩法一句话 + 量化背书/挑战邀请（「1w+人玩过」「挑战模式卷7欢迎尝试」「你能几合赢她？」）

## 3. 用户喜欢什么 / 讨厌什么（评论证据分类）

**喜欢（按出现频次）**
1. 点开即玩零门槛（「高低玩一下」「点开就能直接玩」）
2. 可炫耀的成就/记录（「挖了一万多米」「作者挑战怒冲13万分」）
3. 难度引发的求助与讨论（「11关太难了」「第七关好难」「连败14次你家游戏咋玩啊」——抱怨本身是热评）
4. 作者在场、快速响应（「已经修复了在审核，明天就好了」）
5. 结果可晒（生成器类靠结果图传播）

**讨厌 / 流失点**
1. **找不到入口**（「怎么能在xhs上直接打开」「能不能扫盲一下不知道怎么用」）——组件只在 App 内且位置隐蔽
2. 误触/交互 bug（「下刀时刻容易误触下滑」「改装和退出在一块点不到」）
3. 难而无引导（「连败14次你家游戏咋玩啊」若无攻略承接即劝退）
4. 质量对比落差（拼豆 vs 千岛，19 赞差评）
5. 审核黑盒（创作者侧流失）

## 4. 展示形式的特殊之处（实访结论）

1. **Web 端看不到组件** → 笔记封面/视频必须独立传达「这是能玩的」；视频笔记（点墨成山河）用实机演示画面当封面
2. **笔记正文 = 游戏的一部分**：钻矿大王把存档/纪录写进正文，评论区延续游戏（兑换码、藏宝图、配色分享）——笔记不是广告位，是游戏的外围玩法
3. 通用 CTA 句式：「点击下面👇小工具即可使用」「点击下方「用一用」」
4. 工具型内容**藏/赞比 >0.6**（三星堆 0.73），说明用户以「收藏备用」心态对待——与娱乐型笔记不同
5. 官方组件入口：App 内笔记下方卡片；PC 仅管理上传。**Web 无法试玩**意味着我们的无头测试优势（质量兜底）在评论区口碑战里是差异化武器

## 6. 展示形式线：国风/历史/文物内容，大家爱看什么（8 组关键词 160 条高赞样本）

**被验证的内容需求（按数据强度）**
1. **治愈/解压是最大流量池**：「温馨小游戏丨当我老了…」5.2万赞、「低谷期必玩✨这些游戏带我走出精神内耗」5373、「医生建议病人玩动森」2603——用户找的是**情绪价值**，不是玩法深度
2. **反直觉知识钩子**：「看似绝对公平的抛硬币，为什么你必输无疑？」4万赞、「七夕节是乞巧节」2万赞、「苏轼你没资格写赤壁赋」6823——知识纠正/悖论是文化类的流量密码
3. **文物有情感连接**：物华弥新（文物拟人游戏）玩家去故宫打卡文物原型（「我的鸟音山水钟去哪里了」「海错图换仿品都不带给翻一页的吗」）——**游戏→真实博物馆朝圣**是被验证的行为闭环
4. **文物互动有真实需求**：国美毕设《时光修补者》（文物修复交互游戏）957赞，评论「后面线上可以看或者玩吗？」「博物馆爱好者来辣」；「做了一个三星堆游戏」5547赞
5. **动手体验向**：非遗体验地攻略2846、DIY落叶书签2028、扎燕风筝体验3755——「我也想试」
6. **国风审美消费**：「游戏的国风能有这么多不同的演绎」4079、AIGC国风图万赞级
7. **博物馆搜索的主流是攻略**（免费馆清单/预约指南）——线下需求，线上内容供给以清单体为主

## 8. 综合：需求 × 机制 → 小工具方向

交叉点排序（证据强度 × 与我们的能力匹配）：

1. **文物修复 × 治愈解压**（最强交叉）：修复过程（拂尘、拼对、补配）天然是 ASMR 式治愈体验；需求端有 957 赞「线上能玩吗」+ 5547 赞三星堆游戏 + 5.2万治愈池；我们已有文物修复局引擎。**做法**：把「修复」重定位为「治愈」——慢节奏、过程音效、修复完成的金缮高光时刻，知识卡后置
2. **反直觉文物知识 × 轻互动**：「你以为的 vs 实际的」问答/悖论体（七夕=乞巧节 2万赞验证钩子），配晒图结果卡。成本最低的爆款形态
3. **文物拟人/情感向**：物华弥新验证了情感连接，但需要 IP 运营，重，不做
4. **孙子兵法战棋**：策略深度与碎片场景冲突（空白为什么是空白，见 §5 修正分析）。参赛可以，但定位是「东方审美创意奖」方向，不是流量方向；首次体验必须压缩到 60 秒首胜

**对孙子兵法项目的具体修正**：
- 展示形式学「知识纠正」钩子：笔记内容主打「银雀山竹简里的孙子兵法，和你以为的不一样」（史实钩子），工具作为载体
- 玩法保留但重排：首关改为 60 秒可胜的教学残局；深度关卡后置为「进阶」
- 战报卡增加「冷知识彩蛋」（每篇通关解锁一条竹简冷知识），把知识纠正钩子做进产品内

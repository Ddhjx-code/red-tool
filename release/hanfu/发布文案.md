## 正文

一直想试试汉服是什么样子——
做了个换装小工具：**霓裳羽衣**，妆点一身属于你自己的汉服。🏮

👘 **怎么玩**
① 选发髻：垂髻 / 双丫髻 / 高髻
② 配上衣：交领襦 / 直领袄 / 圆领袍
③ 搭下裙：齐胸襦裙 / 齐腰襦裙 / 马面裙
④ 择一双鞋：绣花鞋 / 弓鞋 / 翘头履
⑤ 再挑个背景：园林 / 桃花林 / 月夜
点一下就换一件，发髻、上衣、下裙、鞋、背景随便混搭，搭出你最喜欢的那一身。

✨ **细节**
· 81 种穿搭组合（含鞋）+ 3 张背景，全部是国风工笔插画风
· 交领右衽、齐胸襦裙、马面裙、翘头履……这些都是汉服里真实的形制
· 搭好了能直接存相册 / 一发笔记，晒出你的汉服

📜 **关于汉服**
汉服是汉民族的传统服饰，「衣冠上国，礼仪之邦」。交领右衽、宽袍大袖，是它最经典的模样。汉服不只是衣服，更是一种礼仪与审美。

搭一身你最喜欢的汉服，评论区晒出来呀～🏮

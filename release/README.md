# 发布目录与系列发布规划

「非遗手作坊」系列每个工具一个独立发布目录：

```
release/
├── README.md            # 本文件：发布规划与进度
└── <工具名>/
    ├── <工具名>.zip      # 上传产物（容器规范见 .skill/）
    ├── 发布文案.md        # 标题/正文/话题/配图顺序
    └── images/           # 发布配图（3:4 竖屏高清截取）
```

发布要求（每篇笔记）：带话题 **#国风vibecoding**、**@科技薯**、**挂载小工具**；T+1 按话题推流。

## 发布节奏建议

- **首发期**：剪纸工坊发布后观察 3-5 天数据（曝光/挂载点击/评论晒图），验证「成品晒图」传播假设，再决定后续工具的互动设计侧重
- **节奏**：每周 1-2 个，保持话题内持续更新；节日向工具（灯谜→元宵/中秋，年画→春节）提前 1-2 周发布
- **系列联动**：每篇文案末尾预告下一个工具；评论区收集「想看哪项非遗」作为选题池
- **数据记录**：发布后在 `docs/series-plan.md` 变更记录中登记发布日期与数据表现
